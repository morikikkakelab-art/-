# Luna クリエイティブ運用ガイドライン

このドキュメントは、Luna（クリエイティブ事業）責任者が従うべき運用ルールです。

---

## 📊 責任者の主要役割

### 1. 撮影実行 + クオリティ管理
- クライアント撮影案件の企画・実行
- 納品物のクオリティ基準を達成
- ビジュアル資産の蓄積

### 2. ブランド設計サポート
- クライアントのブランド世界観を構築
- ビジュアルアイデンティティの提案
- デザイン・色彩・フォントの統一管理

- 撮影技法・ブランド設計の知見をnote記事に
- 美的価値・物語性を重視した発信
- クライアント事例を通じた信頼構築

### 4. 営業（撮影案件特化）
- 撮影依頼のDMテンプレート運用
- 撮影見積もり・提案
- クライアント対応・商談管理

### 5. SNS運用（ビジュアル重視）
- Luna公式アカウント（IG・X・Threads）の運用
- ポートフォリオの発信
- 撮影・ブランド設計の事例紹介

## 📸 撮影プロジェクト管理

### プロジェクトの流れ

```
1. 撮影依頼受付
   ↓
2. 初回ヒアリング・企画
   ↓
3. 撮影準備（機材・ロケ地確認）
   ↓
4. 撮影実行
   ↓
5. レタッチ・編集
   ↓
6. クオリティチェック
   ↓
7. 最終承認
   ↓
8. 納品
   ↓
9. アーカイブ・ナレッジ化
```

### 撮影依頼の種類

1. **商品撮影** - EC・LP・SNS用の商品写真
2. **ブランド撮影** - 企業イメージ・人物・空間撮影
3. **SNS撮影** - Instagram・SNS用の継続的な写真提供
4. **イベント撮影** - セミナー・イベント・キャンペーン撮影

## ✅ クオリティ基準

### 撮影技術基準

**ピント**
- 主要被写体は必ずピントが合っている
- ピンぼけ・浅ぼけの過度な使用は避ける
- 意図的なボケは指示通りか確認

**露出**
- 適正露出（白飛び・黒つぶれなし）
- 意図的なハイキーは事前に相談

**構図**
- 三分割法・対称性・余白のバランス
- クライアント指示と整合性確認
- 素人っぽい構図は避ける

**色合い・色温度**
- ホワイトバランスの正確性
- 色彩の統一感
- 調整後の色がクライアント要望と合致

### ナレッジ記事基準（note）

**内容**
- 撮影技法 or ブランド設計の実用的な知見
- 初心者向けにも分かりやすく
- 具体的な事例・Before/After含む
- 2000文字以上が目安

**表現**
- 物語性・美的価値を重視
- 読む人が「撮影してもらいたい」「ブランド設計したい」と感じるトーン
- 技術的すぎず、親しみやすい文体

**ビジュアル**
- 高品質な画像・写真を複数掲載
- テーマに合った色彩設計
- 動画・スライドショーも活用

### 納品物チェックリスト

**撮影納品時**
- [ ] 撮影データの容量・フォーマット確認
- [ ] ファイル名の統一（日付_案件名_カット番号）
- [ ] RAWデータ + JPG両方か確認
- [ ] メタデータ削除（プライバシー対応）
- [ ] クライアント承認済みか
- [ ] バックアップ完了か

**ブランド設計納品時**
- [ ] デザインガイドライン書（PDF）
- [ ] ロゴ・カラーパレット・フォント定義
- [ ] 使用例・不可パターン説明
- [ ] 編集可能ファイル（AI/PSD）も含む

## 📚 ナレッジ・note記事管理

### 記事の種類

1. **撮影技法記事** - 撮影テクニック・ライティング・構図等
2. **ブランド設計記事** - ブランド構築・配色・世界観作り等
3. **クライアント事例** - 撮影前後・ブランド変身ストーリー
4. **撮影日記** - 現場の気づき・チームの話

### 記事管理ルール

- **保存場所**: `context/Luna.クリエイティブ事業/ナレッジ/`
- **削除厳禁**: すべての記事は蓄積型
- **記事インデックス**: 月ごとに更新
- **タグ付け**: #撮影技法、#ブランド設計、#事例等
- **バージョン管理**: 修正時は _v2, _v3 と番号付け
- **更新頻度**: 月2本以上

### note投稿フロー

1. 記事執筆（初稿）→ `_v1.md`で保存
2. 自己編集・修正 → `_v2.md`
3. 経営者レビュー → `_v3.md`（最終版）
4. noteに投稿 → 有料/無料を決定
5. SNS・HPで告知
6. アクセス数・反応記録

### 月間ノルマ

- **note記事**: 月2本以上
- **撮影技法**: 月1本以上
- **ブランド設計**: 月1本以上
- **クライアント事例**: 月1本以上
- **ポートフォリオ更新**: 随時（新規案件終了後）

## 📱 SNS運用ルール

### ポジショニング

**Luna公式アカウント**
- **メッセージ**: 「あなたのブランドの価値を、写真で伝える」
- **ターゲット**: 中小企業経営者・起業家・EC事業者
- **トーン**: 美的・プロフェッショナル・信頼感

### 投稿内容（4本柱）

1. **撮影サンプル/ポートフォリオ** (40%)
   - 美しい撮影作品のシェア
   - Before/After比較
   - 撮影現場の風景

2. **ブランド設計事例** (25%)
   - ビジュアルアイデンティティの提案事例
   - クライアントのブランド変身ストーリー
   - カラー・デザイン解説

3. **撮影TipsやBTS** (20%)
   - Behind The Scenes（制作現場）
   - 撮影テクニックの短解説
   - 機材・セットアップ紹介

4. **note記事告知・業界情報** (15%)
   - 新記事の告知
   - トレンド・新しい撮影手法の紹介

### 投稿頻度

- **Instagram**: 1日1投稿（リール週2本以上推奨）
- **X**: 1日1-2ツイート（撮影・ブランド情報）
- **Threads**: 週3-4投稿（ビジネス向け会話型）
- **ストーリーズ**: 2-3回/日

### 最適投稿時間

- **朝8時**: 経営者層がアクティブ
- **昼12時**: SNS活用企業向け
- **夜19時-20時**: クリエイター層がアクティブ

## 🎨 その他の管理項目

### ポートフォリオ管理

- すべての撮影作品をポートフォリオに蓄積
- 定期更新（最新3ヶ月の作品を常にTop表示）
- クライアント別、撮影種別で分類
- HP・SNS・提案資料に活用

### クライアント事例の許可管理

- ビフォーアフターを使うときは必ず許可取得
- 許可内容を記録（どの媒体まで使用可か等）
- 無許可での公開は厳禁

### 撮影機材・セット管理

- 使用機材リスト（カメラ・レンズ・照明等）
- メンテナンススケジュール
- 消耗品の在庫管理
- 購入・レンタル計画

### 撮影チーム管理

- 外注スタッフとの連絡
- スケジュール調整
- 支払い・請求管理
