# Luna クリエイティブ運用ガイドライン

このドキュメントは、Luna（クリエイティブ事業）責任者が従うべき運用ルールです。

---

## 📊 責任者の主要役割

### 1. 撮影・ブランド設計実行
- クライアント撮影案件の企画・実行・納品
- ブランド設計・ビジュアルアイデンティティの構築
- 高品質な撮影物とクリエイティブの納品

### 2. ナレッジ記事化（note）
- 撮影技法・ブランド設計の知見をnote記事で発信
- 学んだことを蓄積し、クライアント信頼構築に活用
- 成功事例・失敗事例をナレッジベース化

### 3. 営業サポート
- 撮影依頼のDMテンプレート運用
- 撮影見積もり・提案
- クライアント対応・商談管理

### 4. SNS運用（ビジュアル重視）
- Luna公式アカウント（IG・X・Threads）の運用
- ポートフォリオの発信
- 撮影・ブランド設計の事例紹介

---

## 📚 ナレッジ・記事管理ルール

### 記事の種類

1. **撮影知見note記事** - 撮影技法・ライティング・構図等
2. **ブランド設計note記事** - ブランド構築・配色・世界観設計等
3. **クライアント事例** - Before/After・ブランド変身ストーリー
4. **ポートフォリオ** - 撮影作品の蓄積・分類

### 記事の保存ルール
- **削除厳禁**: すべての記事は `context/Luna.クリエイティブ事業/ナレッジ/` に保存
- **記事インデックス**: 月ごと・テーマごとにインデックスを作成
- **タグ付け**: 記事に関連キーワード・タグをつける
- **バージョン管理**: 修正時は `_v2`, `_v3` と番号を付ける
- **関連リンク**: 関連する他の記事へのリンクを記載

### 月間ノルマ
- **撮影知見記事**: 月1本以上
- **ブランド設計記事**: 月1本以上
- **クライアント事例**: 月1本以上
- **ポートフォリオ更新**: 随時（新規案件終了後）
- 記事は `[日付]_[タイプ]_[タイトル]_v1.md` の形式で命名

### note発行戦略
- **無料**: 基本知識・導入編
- **有料(500円)**: 実践的テクニック
- **有料(1000円)**: 深掘り解説・ケーススタディ

## 💼 営業管理ルール

### DM・提案テンプレート
- **撮影ビジュアル訴求型**: ポートフォリオで信頼感を伝える
- **事例訴求型**: 成功事例でニーズを喚起
- テンプレートは `context/Luna.クリエイティブ事業/営業管理/DMテンプレート/` に保存

### 撮影依頼管理シート
- **統一シート管理**: すべての撮影案件を1つのシートで管理
- **記載項目**:
  - 案件名・クライアント
  - 撮影種別（商品/ブランド/SNS継続/イベント等）
  - 撮影日・納期・予算
  - 進捗ステータス（企画中/見積待ち/撮影準備中/撮影完了/レタッチ中/チェック中/納品完了）
  - 次のアクション

### 撮影見積もりテンプレート
- 撮影内容・料金・納期を明記
- 撮影時間数・レタッチ・交通費等を明確化
- キャンセルポリシー、支払い条件を記載

### 商談ログ
- すべての商談内容を記録
- 議事録形式で：日時・参加者・決定事項・次のアクション
- `context/Luna.クリエイティブ事業/営業管理/商談ログ・顧客対応/` に保存

### 営業フロー
1. DM送信（テンプレート使用）
2. 返信確認 → シートに記入
3. 初回面談・ヒアリング → 商談ログ記入
4. 見積提出 → シート更新
5. クライアント承認 → 撮影実行
6. 納品 → 案件化・完了

## 📱 SNS運用ルール（媒体別）

### 対象媒体
1. **Instagram** - ビジュアル・ポートフォリオ重視
2. **X** - ビジネス情報・トレンド発信
3. **Threads** - 対話型・ビジネス展開

### 各媒体別の構成要素

#### 1️⃣ 運用戦略
- **フォロワー目標**: 月ごとの目標フォロワー数
- **ターゲット設定**: ペルソナ・顧客層の定義
- **ポジショニング**: 「あなたのブランドの価値を、写真で伝える」
- **投稿方針**: トーン&マナー、ビジュアル世界観、禁止事項
- 保存先: `context/Luna.クリエイティブ事業/SNS運用/[媒体]/運用戦略.md`

#### 2️⃣ コンテンツ企画・台本
- **コンテンツピラー**: ポートフォリオ・メイキング・Tips・note告知等
- **企画シート**: テーマ・訴求ポイント・ターゲットを明記
- **台本テンプレート**: キャプション案・ハッシュタグ案
- 保存先: `context/Luna.クリエイティブ事業/SNS運用/[媒体]/コンテンツ企画・台本/`

#### 3️⃣ 投稿管理（進捗管理）
- **コンテンツカレンダー**: 月間の投稿スケジュール
  - 投稿日時・内容・担当者
  - 進捗ステータス（企画中/制作中/レビュー中/承認済み/投稿済み）
- **投稿チェックリスト**: 誤字脱字・ブランド準拠・リンク等
- 保存先: `context/Luna.クリエイティブ事業/SNS運用/[媒体]/投稿管理/`

#### 4️⃣ 投稿分析
- **月間レポート**: パフォーマンス分析
  - リーチ・インプレッション・エンゲージメント数・率
  - フォロワー増加数
  - トップ・ロー3投稿の分析
- **投稿別分析**: 各投稿のパフォーマンス記録
- 保存先: `context/Luna.クリエイティブ事業/SNS運用/[媒体]/投稿分析/`

#### 5️⃣ 改善PDCA
- **Plan**: 前月分析から改善施策を策定
- **Do**: 施策を実行
- **Check**: パフォーマンスを検証
- **Action**: 次のアクションを決定
- 保存先: `context/Luna.クリエイティブ事業/SNS運用/[媒体]/改善PDCA/`

## 📊 投稿方針（各媒体別）

### Instagram
- **投稿頻度**: 1日1投稿（毎日）+ リール週2回以上
- **コンテンツ**: ポートフォリオ(35%) / メイキング(30%) / Tips(25%) / note告知(10%)
- **目標**: 月+200フォロワー、ER 6%以上

### X
- **投稿頻度**: 1日1-2ツイート
- **コンテンツ**: 知見(40%) / 事例(30%) / トレンド(20%) / note告知(10%)
- **目標**: 月+100フォロワー、月30エンゲージメント以上

### Threads
- **投稿頻度**: 週3-4回（スレッド型・対話型）
- **コンテンツ**: 深掘り解説(40%) / Q&A(35%) / 思考シェア(20%) / その他(5%)
- **目標**: 月+80フォロワー、月100エンゲージメント以上

## 📈 月間運用フロー

### 月初（1-5日）
1. 前月の撮影案件アーカイブ・ナレッジ化
2. クライアント成果分析
3. 月間撮影スケジュール確定
4. note記事テーマ決定（2本分）
5. SNS投稿計画表作成

### 月中（6-25日）
1. 撮影案件実行・進捗管理
2. note記事執筆（週1本のペース）
3. 日々のSNS投稿
4. クライアント商談実施
5. ポートフォリオ更新

### 月末（26-30日）
1. 月間撮影完了分の納品完了
2. 月間売上確定・経理への報告
3. SNS月間分析
4. note月間成果確認（PV・売上）
5. 翌月計画確認・経営者報告
