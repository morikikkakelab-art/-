## 管理項目詳細

### 基本情報
- **案件名**: 分かりやすい名前（〇〇社_商品撮影など）
- **クライアント**: 企業名
- **撮影種別**: 商品 / ブランド / SNS継続 / イベント等
- **予算**: 総額（税別）
- **責任者**: Luna / 外注スタッフ等

### スケジュール
- **撮影日**: 実施予定日（複数日の場合は「2026-05-15~17」等）
- **納期**: クライアント納品予定日
- **レタッチ期間**: 撮影日から納期までの日数（5営業日以上確保）

### 内容詳細
- **撮影カット数**: 何カット撮影するか
- **特殊要件**: ドローン・スタジオ・ロケ地等の特別対応
- **使用機材**: 使用予定カメラ・レンズ
- **スタッフ配置**: 撮影・アシスタント人数

### 進捗追跡
- **現在の進捗**: 上記ステータスから選択
- **最終更新日**: いつ更新したか
- **次のアクション**: 次に何をするか、期限は？
- **備考**: 特別な指示・注意点

## トラブル時の対応

### 撮影延期が発生した場合
1. 直ちにクライアントに連絡
2. 新しい撮影日を提案
3. レタッチ期間を調整
4. 他の案件への影響確認

### クオリティ問題が発生した場合
1. 原因を特定（撮影 / 環境 / 機材等）
2. 再撮影が必要か判定
3. クライアントに報告・相談
4. 解決後に改善策を記録

### 納期に間に合わない場合
1. 即座に経営者・クライアントに報告
2. 可能な限り前倒しする施策を実行
3. クライアントの他業務への影響確認
4. 遅延理由と対策を記録
