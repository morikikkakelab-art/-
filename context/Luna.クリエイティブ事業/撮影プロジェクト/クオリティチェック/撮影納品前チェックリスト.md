# 撮影納品前チェックリスト

納品前の最終確認。これをすべてクリアしてからクライアントに納品する。

---

## 撮影技術チェック（各カット）

### ピント・フォーカス
- [ ] 主要被写体がシャープにピントしているか
- [ ] ピントずれている写真がないか
- [ ] 意図的なボケは指示通りか
- [ ] ピント位置は適切か（目線ピント、商品の一番見せたい部分など）

**判定**: ◎ 問題なし / △ 1-2カット要修正 / ✗ 要再撮影

---

### 露出・明るさ
- [ ] 適正露出か（白飛び・黒つぶれなし）
- [ ] 意図的なハイキーは事前指示通りか
- [ ] 全体的に暗すぎ・明るすぎないか
- [ ] 影のバランスは適切か

**判定**: ◎ 問題なし / △ 1-2カット要修正 / ✗ 要再撮影

---

### 構図・フレーミング
- [ ] 三分割法・ルール・オブ・サードを活用しているか
- [ ] 余白のバランスが取れているか
- [ ] 被写体が画面に収まっているか（フレーム外にはみ出していないか）
- [ ] 不要なものが映り込んでいないか
- [ ] 素人っぽい構図になっていないか

**判定**: ◎ 問題なし / △ 1-2カット要再構図 / ✗ 要再撮影

---

### 色合い・色温度・ホワイトバランス
- [ ] ホワイトバランスは正確か（色かぶりなし）
- [ ] クライアント指示の色味になっているか
- [ ] 色彩の統一感があるか（全体で色が揺らいでいないか）
- [ ] 色が不自然でないか（オレンジかぶり・青かぶり等）
- [ ] レタッチ後の色が自然か

**判定**: ◎ 問題なし / △ 1-2カット要色補正 / ✗ 要再撮影

---

### 背景・環境
- [ ] 背景はクライアント指示通りか
- [ ] 不要な背景の映り込みがないか
- [ ] 背景削除が必要な場合、クオリティは高いか
- [ ] 背景とのコントラストは適切か
- [ ] 照明の影がうまく表現されているか

**判定**: ◎ 問題なし / △ 1-2カット要修正 / ✗ 要再撮影

---

## データ管理チェック

### ファイル形式・容量
- [ ] JPGフォーマットで出力されているか
- [ ] RGB色空間か（CMYKではないか）
- [ ] 解像度は350dpi以上か
- [ ] ファイルサイズは適切か（1-5MB程度）
- [ ] 圧縮レベルは適切か（品質損失がないか）

### ファイル命名
- [ ] ファイル名は統一されているか
- [ ] ファイル名は分かりやすいか
  - 例：「A社_商品_001」「A社_商品_LS_002」
- [ ] 日本語が含まれていないか（互換性の問題）
- [ ] 連番は01, 02, 03... と統一されているか

### ファイル整理
- [ ] フォルダ構成は分かりやすいか
- [ ] 要不要カットの分類はされているか
- [ ] 最終納品版と未編集RAWデータは分かれているか
- [ ] バックアップは複数環境に保存されているか

---

## クライアント指示対応チェック

### 指示内容の反映
- [ ] クライアントからの指示をすべて反映したか
- [ ] 「修正お願いします」と言われた箇所は修正されているか
- [ ] スタイルガイド（あれば）に従っているか
- [ ] プロダクト認識は正確か（型番、色、配置等）

### 納品数量
- [ ] 指示通りのカット数か
- [ ] 要不要カットの分類は正確か
- [ ] ボーナスカット（追加提供分）は明示されているか

---

## 最終確認

### 総合的な品質判定
```
◎ エクセレント：クライアント期待値以上。即納品可
○ グッド：基準クリア。納品可
△ フェア：修正が必要。修正後納品
✗ ポア：要再撮影。これでは納品不可
```

### 修正が必要な場合
- [ ] 修正内容をリスト化したか
- [ ] 修正期間を明示したか
- [ ] クライアントに進捗を報告したか

### 最終承認
- [ ] Luna責任者が確認したか
- [ ] 経営者が確認したか（重要案件）
- [ ] 納品準備は完了したか

---

## レタッチ前チェック

### RAW現像
- [ ] RAWデータは正しく現像されたか
- [ ] 露出補正は適切か
- [ ] ホワイトバランスは正確か
- [ ] コントラスト・彩度は自然な範囲か

### 基本レタッチ
- [ ] クロップは指示通りか
- [ ] 色褪せ・色かぶりは修正されたか
- [ ] 不要なゴミ・傷は削除されたか
- [ ] 照明の不均一さは補正されたか

### 高度なレタッチ（オプション）
- [ ] 背景削除は高クオリティか
- [ ] 物体の加工（サイズ変更等）は自然か
- [ ] 合成画像は違和感がないか

---

## チェック完了後

1. **チェックシートに署名**（チェック者：名前・日付）
2. **修正内容をまとめる**（必要な場合）
3. **クライアント確認依頼を送付**
4. **クライアント承認メールを待つ**
5. **承認後、最終納品の手配**
