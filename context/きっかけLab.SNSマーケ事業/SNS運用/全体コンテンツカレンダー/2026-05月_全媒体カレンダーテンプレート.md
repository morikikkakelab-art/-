## 投稿チェックリスト（投稿前確認）

各投稿、以下の項目をチェックしてから投稿してください：

- [ ] 誤字脱字がないか
- [ ] リンクは正しいか
- [ ] ハッシュタグは30個以内か（Instagram）
- [ ] 画像解像度は適切か（1080×1350）
- [ ] 色合いはブランドイメージに合致しているか
- [ ] クライアント情報は非公開か
- [ ] 法的問題がないか
- [ ] 投稿時間は最適か

## 進捗ステータス説明

| ステータス | 意味 | 担当 | 次のステップ |
|----------|------|------|----------|
| 企画中 | コンテンツ方向性を検討中 | きっかけLab. | 台本・構成案作成 |
| 制作中 | 画像・動画・テキスト制作中 | 制作チーム | 完成後レビュー提出 |
| レビュー中 | 責任者によるチェック中 | 責任者 | OK → 承認済みに |
| 承認済み | 最終OKが出た | 経営者 | 投稿日時通りに投稿 |
| 投稿済み | 実際に投稿された | きっかけLab. | 分析・反応モニタリング |

## トラブル時の対応

### 投稿遅延が発生した場合
1. 責任者に直ちに報告
2. 次の投稿で調整するか、別日に移行するか判断
3. 月間目標の方針変更がないか確認

### 誤投稿/不適切投稿
1. 直ちに削除
2. 原因分析をする
3. 再度チェック体制を確認
4. 経営者に報告
