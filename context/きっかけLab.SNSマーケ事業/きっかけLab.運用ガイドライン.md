# きっかけLab. SNSマーケティング運用ガイドライン

このドキュメントは、きっかけLab.（SNSマーケ事業）責任者が従うべき運用ルールです。

---

## 📊 責任者の主要役割

### 1. リサーチ → 成果物出力（コスト化）
- SNSマーケティングの最新情報・トレンドを定期的にリサーチ
- リサーチ結果を分析し、クライアント支援の施策に反映
- 学んだことをナレッジ記事・コラムとして形式化（成果物化）

### 2. ナレッジ・記事管理（蓄積型）
- 記事を消さず、すべて保存し蓄積する
- 業界トレンド、成功事例、失敗事例をまとめる
- クライアント対応で参考になる事例をナレッジベース化

### 3. 営業サポート
- DM・提案テンプレートの作成・管理
- 商談進捗の記録と管理
- クライアント情報の一元化

### 4. SNS運用実行（各媒体別PDCA）
- 運用戦略の立案・実行
- コンテンツ企画・制作
- 投稿スケジュール管理
- パフォーマンス分析
- 分析に基づく改善施策の実行

---

## 📚 ナレッジ・記事管理ルール

### 記事の種類
1. **HPコラム記事** - クライアント向け教育コンテンツ
2. **業界トレンド記事** - SNSマーケ関連の最新情報
3. **リサーチログ** - 日々の学習・インプット記録
4. **成功事例・失敗事例** - クライアント案件から学んだこと

### 記事の保存ルール
- **削除厳禁**: すべての記事は `context/きっかけLab.SNSマーケ事業/ナレッジ/` に保存
- **記事インデックス**: 月ごと・テーマごとにインデックスを作成
- **タグ付け**: 記事に関連キーワード・タグをつける
- **バージョン管理**: 修正時は `_v2`, `_v3` と番号を付ける
- **関連リンク**: 関連する他の記事へのリンクを記載

### 月間リサーチノルマ
- **新規トレンド記事**: 月5本以上
- **クライアント向けコラム**: 月3本以上
- **学習ログ**: 週2回以上
- 記事は `[日付]_[タイプ]_[タイトル]_v1.md` の形式で命名

## 💼 営業管理ルール

### DM・提案テンプレート
- **初期接触テンプレート**: 新規顧客への第一報
- **提案テンプレート**: サービス内容・価格・納期を明記
- **フォローアップテンプレート**: 未返信時の追い打ち
- テンプレートは `context/きっかけLab.SNSマーケ事業/営業管理/DMテンプレート/` に保存
- テンプレートを使った実例は別途記録

### DM進捗・顧客管理シート
- **統一シート管理**: すべての顧客対応を1つのシートで管理
- **記載項目**:
  - 顧客名・企業名
  - 接触日
  - 最後の対応内容・日時
  - 現在のステータス（見込み/商談中/契約待ち/契約済み）
  - 予想受注日
  - 重要な要望・ニーズ
  - 次のアクション

### 商談ログ
- すべての商談内容を記録
- 議事録形式で：日時・参加者・決定事項・次のアクション
- `context/きっかけLab.SNSマーケ事業/営業管理/商談ログ/` に保存

### 営業フロー
1. DM送信（テンプレート使用）
2. 返信確認 → シートに記入
3. 初回面談 → 商談ログ記入
4. 提案資料送付 → シート更新
5. 契約 → 案件化・チーム共有

## 📱 SNS運用ルール（媒体別PDCA）

### 対象媒体
1. **Instagram** - ビジュアル・ストーリーズ中心
2. **X** - リアルタイム・トレンド情報発信
3. **Threads** - 会話型・コミュニティ形成

### 各媒体別の構成要素

#### 1️⃣ 運用戦略
- **フォロワー目標**: 月ごとの目標フォロワー数
- **ターゲット設定**: ペルソナ・顧客層の定義
- **ポジショニング**: 競合分析・自社の立場の明確化
- **投稿方針**: トーン&マナー、主要テーマ、禁止事項
- **エンゲージメント目標**: エンゲージメント率の目標値
- 保存先: `context/きっかけLab.SNSマーケ事業/SNS運用/[媒体]/運用戦略.md`

#### 2️⃣ コンテンツ企画・台本
- **コンテンツピラー**: 投稿テーマの柱（教育・事例・ニュース等）
- **企画シート**: テーマ・訴求ポイント・ターゲットを明記
- **台本テンプレート**: 画像説明・キャプション案・ハッシュタグ案
- **クリエイティブ指示**: 画像・動画の作成指示書
- 保存先: `context/きっかけLab.SNSマーケ事業/SNS運用/[媒体]/コンテンツ企画・台本/`

#### 3️⃣ 投稿管理（進捗管理）
- **コンテンツカレンダー**: 月間の投稿スケジュール
  - 投稿日時
  - 投稿内容（タイトル）
  - 担当者
  - 進捗ステータス（企画中/制作中/レビュー中/承認済み/投稿済み）
- **投稿チェックリスト**: 投稿前の確認項目（誤字脱字・ブランド準拠・リンク等）
- 保存先: `context/きっかけLab.SNSマーケ事業/SNS運用/[媒体]/投稿管理/`

#### 4️⃣ 投稿分析
- **月間レポート**: 各月のパフォーマンス分析
  - 総リーチ数
  - 総インプレッション
  - エンゲージメント数（いいね・コメント・シェア）
  - エンゲージメント率
  - フォロワー増加数
  - トップパフォーマンス投稿（Top3）
  - 低パフォーマンス投稿
- **投稿別分析**: 各投稿のパフォーマンス記録
  - 投稿日
  - 投稿内容
  - リーチ数
  - エンゲージメント数
  - 反応パターン（コメント内容・質問多数等）
- 保存先: `context/きっかけLab.SNSマーケ事業/SNS運用/[媒体]/投稿分析/`

#### 5️⃣ 改善PDCA
- **Plan（計画）**: 前月の分析から新月の改善施策を策定
  - 改善テーマ（投稿時間帯変更・コンテンツ内容変更等）
  - 施策の詳細
  - 期待効果
- **Do（実行）**: 施策を実際に実行
  - 実行開始日
  - 実行内容の詳細記録
- **Check（検証）**: 結果を分析
  - パフォーマンス変化
  - 効果測定（成功/失敗の判定）
- **Action（改善）**: 次のアクションを決定
  - 継続するもの
  - 中止するもの
  - 新規施策
- 保存先: `context/きっかけLab.SNSマーケ事業/SNS運用/[媒体]/改善PDCA/`

## 📈 月間運用フロー

### 月初（1-5日）
1. 前月の投稿分析レポート完成
2. 前月の改善PDCAサイクル完了
3. 今月の運用戦略を確認
4. 月間コンテンツカレンダー作成
5. 経営者に月初報告

### 月中（6-25日）
1. 日々の投稿スケジュール通りに実行
2. 週1回のパフォーマンス確認
3. 低パフォーマンス投稿への対応（リポスト等）
4. エンゲージメント対応（コメント返信・DM対応）
5. リサーチ・ナレッジ記事の作成

### 月末（26-30日）
1. 全投稿のパフォーマンスデータ収集
2. 月間分析レポート作成
3. クライアント別レポート準備
4. 翌月の改善施策検討会議
5. 月末報告書提出

## 🔄 リサーチ → 成果物化のプロセス

### Step 1: リサーチ・学習
- Twitter/LinkedIn/ブログから最新情報を収集
- リサーチログに記録：日時・情報源・要点・洞察

### Step 2: 分析・考察
- 情報の価値判定：クライアント対応に使えるか？
- 自社/クライアントへの応用可能性を分析
- 関連する既存ナレッジとの比較

### Step 3: 成果物化
- HPコラム記事（クライアント向け教育）
- トレンド記事（業界分析）
- 運用施策への反映（即座に活用）

### Step 4: 保存・蓄積
- `context/` フォルダに分類して保存
- インデックスに記入
- 関連記事にリンク
