## ステータス定義

- **見込み**: DM送信・返信待ち
- **初回接触**: 返信あり、次のステップ待機
- **商談中**: 本格的な打ち合わせ開始
- **提案待ち**: クライアント側の内部検討中
- **検討中**: 見積書・提案資料検討中
- **契約待ち**: 承認待ち・契約手続き中
- **契約済み**: 契約確定（案件化）
- **失注**: 断定・別企業選択

## 月間営業目標の例

- **新規DM送信**: 15社以上
- **返信率**: 30%以上
- **初回面談実施数**: 5社以上
- **新規契約数**: 3社以上

## 工程別アクション例

### 見込み段階（DM送信直後）
- [ ] DM送信日を記録
- [ ] 3日後にフォローアップスケジュール登録

### 初回接触（返信あり）
- [ ] 返信内容を記録
- [ ] 24時間以内に返信
- [ ] 初回面談日程を提案
- [ ] 面談の日時を設定

### 商談中（面談実施）
- [ ] 商談ログを別ファイルで記入
- [ ] クライアント課題・ニーズを明記
- [ ] 提案資料作成スケジュール設定

### 提案・検討中
- [ ] 提案金額を記入
- [ ] フォローアップ日程を設定
- [ ] クライアントの決定スケジュール確認

### 契約段階
- [ ] 契約金額を確定
- [ ] 契約書作成・署名
- [ ] 全社共有（経営者・経理責任者）

## 定期レビュー項目

**毎週金曜**
- 新規見込み数
- 商談中の件数
- 契約待ちの件数

**毎月末**
- 月間契約数
- 受注金額
- 失注分析（なぜ失注したか）
- 次月施策

## 顧客情報の保護

- このシートは機密情報です
- メール・SNSでの共有は禁止
- 共有ドライブの暗号化フォルダに保存
- 外部への共有は経営者の許可が必須
