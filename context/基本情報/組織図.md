# 組織図・体制

## CEO（最高経営責任者）
- 役割：全体経営判断、事業戦略

## 5つの職務分担

### 1. きっかけLab.責任者（SNSマーケ事業）
- ナレッジ：SNSマーケ向けHPコラム、業界トレンド記事
- 営業：SNS支援サービスのDMテンプレ、商談ログ管理
- SNSマーケ：きっかけLab.公式IG・X・Threads運用

### 2. Luna責任者（クリエイティブ事業）
- ナレッジ：撮影・ブランド設計の知見をnote記事に
- 営業：撮影案件のDMテンプレ、顧客対応・商談ログ
- SNSマーケ：Luna公式IG・X・Threads運用

### 3. 経理責任者
- 売上管理
- 経費管理
- 請求書発行・回収

### 4. 技術・商品企画責任者
- ツール開発
- 自動化プロジェクト
- テック戦略

### 5. 事業改善責任者
- スクール事業運営
- コミュニティ運営
- 全体改善施策
