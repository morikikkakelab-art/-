# 全体共通・管理

事業を横断して必要な共通スキル・ナレッジをまとめています。

## カテゴリー

### ナレッジ・スキル
- **ナレッジ・コンテンツ戦略**: コンテンツ企画の基本フレームワーク、ターゲット設定、トーンマナー統一
- **初心者向け言葉選びガイドライン**: 複雑な用語の簡潔な説明、読みやすい文章の書き方

### 機能別スキル（今後拡充予定）
- **財務管理**: 売上・経費・請求書管理
- **技術・商品企画**: ツール開発・機能要望管理
- **事業改善**: KPI管理・改善施策・コミュニティ運営
- **認証情報管理**: Slack・Notion などの認証情報管理

## 適用対象者

| スキル | 対象者 |
|--------|--------|
| ナレッジ・コンテンツ戦略 | 全員 |
| 初心者向け言葉選びガイド | きっかけMedia責任者 |
