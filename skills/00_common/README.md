# 共通スキル

全5名の社員エージェントが共有する基礎スキルと知識をまとめています。

## 📋 スキル一覧

### 1. ナレッジ・コンテンツ戦略
- コンテンツ企画の基本フレームワーク
- ターゲット設定・トーンマナー統一
- エンゲージメント向上のためのコンテンツ設計

### 2. 初心者向け言葉選びガイドライン
- 複雑な用語の簡潔な説明方法
- 読みやすく分かりやすい文章の書き方
- HP記事・note・SNS投稿での活用

### 3. 記事作成コンサルタント
- 記事企画から執筆・公開までの全プロセス
- SEO対策・キーワード戦略
- 品質チェックリスト

## 🎯 各スキルの適用シーン

| スキル | 誰が使うか | タイミング |
|--------|-----------|----------|
| ナレッジ・コンテンツ戦略 | 全員 | コンテンツ企画時 |
| 初心者向け言葉選びガイドライン | きっかけLab責任者 | HP・note記事制作時 |
| 記事作成コンサルタント | きっかけLab責任者 | 記事企画・制作時 |
