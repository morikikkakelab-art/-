# ナレッジ・コンテンツ戦略 スキル仕様書

**作成日**: 2026-05-07  
**対象事業**: きっかけLab.（SNSマーケ事業）、Luna（クリエイティブ事業）

---

## 📌 スキルの目的

社内で蓄積された知見・経験・成功事例を、**顧客にとって価値あるコンテンツ**に変換し、以下を実現する：
- **ブランド認知・信頼構築**
- **オーガニック流入（SEO）の増加**
- **顧客問い合わせ・受注の創出**
- **社内ナレッジの可視化と共有**
- **継続的な改善と最適化**

---

## 🎯 責務

### 1. ナレッジベース構築・管理
- **社内知見の収集**: 各責任者から成功事例・失敗事例を定期的にヒアリング
- **整理・体系化**: 業界知識、方法論、テクニック、事例を体系化
- **鮮度維持**: 月1回、最新の知見を反映するため更新
- **検索性向上**: タグ・カテゴリ・キーワード で検索しやすく

### 2. 事業別コンテンツ戦略

#### きっかけLab.（SNSマーケ事業）
- **コア知識**: SNS運用、Instagram/TikTok/X戦略、クリエイティブ制作
- **コンテンツ形式**: note、ホワイトペーパー、YouTube動画、ウェビナー
- **ターゲット読者**: 中小企業オーナー、マーケティング初心者、起業家
- **ボリューム目標**: 月4〜6記事、月 3,000ビュー以上

#### Luna（クリエイティブ事業）
- **コア知識**: ブランド設計、フォトシューティング技法、色彩理論、世界観構築
- **コンテンツ形式**: HPコラム、Instagram、Pinterest、事例ギャラリー
- **ターゲット読者**: ビジュアル重視の企業、ブランド構築を考える経営者
- **ボリューム目標**: 月2〜3記事、月 1,500ビュー以上

### 3. 成長分析と最適化
- **アクセス分析**: Google Analytics で流入元、滞在時間、クリック先を分析
- **エンゲージメント分析**: シェア数、コメント数、セーブ数を追跡
- **CVR分析**: どのコンテンツから問い合わせが生まれているか
- **A/Bテスト**: タイトル、サムネイル、CTA文言 を改善
- **月次報告**: 成長指標と改善施策を月次レポートで共有

### 4. SEO・ソーシャル最適化
- **キーワード戦略**: 月間検索ボリュームとライバル度を分析し、狙うべきキーワード決定
- **タイトル・見出し最適化**: クリック率が高くなるタイトルテクニック を応用
- **内部リンク戦略**: 関連記事を相互参照し、サイト滞在時間を延長
- **SNS拡散戦略**: 投稿時間、ハッシュタグ、リール動画化
- **バックリンク獲得**: 提携サイトやインフルエンサーに記事を紹介してもらう

### 5. 顧客ターゲットセグメント別アプローチ
- **SNS初心者向け**: 基本から実践まで、ステップバイステップで学べる内容
- **既に運用中の企業向け**: より高度な戦略・分析・改善ノウハウ
- **事業拡大を考える経営者向け**: ROI・コスト意識を持った実践的なコンテンツ
- **デザイン・ブランドを重視する企業向け**: ビジュアルの重要性、制作フロー

### 6. コンテンツカレンダー・スケジュール管理
- **月間企画会議**: テーマ、キーワード、公開日を決定
- **編集カレンダー**: 全記事の執筆スケジュール、修正、公開日を一元管理
- **継続性**: 月 4記事以上を安定して公開

## 🔍 初心者向けガイドライン

### 言葉選びの原則
- **1文は30〜50字に**: 長い文は読みにくい
- **難しい用語は定義をつける**: 「SNSマーケティング（＝ソーシャルメディアを使った販売促進）」
- **抽象的な表現は避ける**: 「効果的」→「3ヶ月で問い合わせ 30%増加」
- **数字・具体例を入れる**: 根拠を示し信頼性を高める
- **読者目線で**: 「私たちは〜」ではなく「あなたは〜」

### 記事構成テンプレート
```
【タイトル】 ← クリックしたくなる言葉遣い
【リード（冒頭100字）】 ← 問題提起 + 記事で得られる価値
 ↓
【目次】 ← 記事全体の概要
 ↓
【本文】
  1. 背景・問題提起
  2. 解決策（ステップバイステップ）
  3. 実例・ケーススタディ
  4. よくある質問 (FAQ)
 ↓
【まとめ】 ← 要点と次のアクション
【CTA】 ← 問い合わせ、資料請求、フォロー
```

### コンテンツチェックリスト
- [ ] タイトルは「クリックしたくなる」か？
- [ ] 冒頭で「この記事で何が学べるか」明確か？
- [ ] 難しい用語は全て定義されているか？
- [ ] 1段落が5〜8文以内か？
- [ ] 図表・画像が適切に配置されているか？
- [ ] 読者が次に何をすべきか明確か？

## 🔄 継続改善（PDCA）の具体例

### 例：「Instagram運用初心者向けガイド」の改善
```
【Plan（計画）】
- キーワード「Instagram 運用 初心者」で上位30位以内を目指す
- 月 1,000ビュー以上を目標に

【Do（実行）】
- 初稿を執筆・公開
- Instagram、note でシェア

【Check（確認）】
- 1ヶ月後、300ビュー → 目標未達（30%）
- 滞在時間は平均 2.5分（目標 3分未満）
- 「本当に初心者向けなのか？」というコメント

【Act（改善）】
- 冒頭の問題提起をもっと具体的に
- 図表を3枚追加し、視覚的に分かりやすく
- 難しい用語をさらに噛み砕く
- 「やってみた人からの質問」セクションを追加
- 改訂版公開 → 2ヶ月目に 600ビュー（前月比 +100%）
```
