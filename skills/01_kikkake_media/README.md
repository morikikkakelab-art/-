# きっかけLab.責任者スキル

SNSマーケティング支援事業の統括責任者として必要なスキル・知識・実行プロセスをまとめています。

## 🎯 責任者の役割

### コアスキル
- **SNS戦略立案**: Instagram, X, Threads での投稿戦略設計
- **コンテンツ企画**: 高エンゲージメントを得られるコンテンツの企画・制作
- **顧客営業**: クライアント開拓・関係構築
- **分析・改善**: SNS分析データの解釈と PDCA 実行

### 主な業務
- SNS運用カレンダーの作成・管理
- 毎日1投稿以上の投稿管理
- クライアント開拓・商談対応
- 月間売上・KPI 管理

## 📊 成功指標（KPI）
- 新規クライアント数: 月3件以上
- クライアント継続率: 90%以上
- 月間売上: 目標達成
