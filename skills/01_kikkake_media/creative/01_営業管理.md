# 営業進捗管理

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 高  
**習得期間**: 1-2週間  
**最終更新**: 2026年5月8日

---

## 📋 概要

営業進捗管理は、クライアントとの商談から契約までのすべてのプロセスを記録・管理し、月間売上目標の達成を推進するスキルです。

**目的**:
- 全商談の進捗を一元管理
- 売上予測・目標達成を可視化
- クライアント関係を体系的に構築
- 逃し案件を最小化

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

- ✅ 商談から契約までのプロセスを正確に記録
- ✅ Notion の「商談ログ」データベースを効率的に運用
- ✅ 月間売上目標の進捗を常に把握
- ✅ クライアント対応の優先順位を適切に判断
- ✅ CEO への営業報告を迅速に提出

---

## 🔧 実行手順

### **ステップ1：商談前の準備（初期接触時）**

#### 1-1. クライアント情報の収集
```
【確認すべき情報】
- 企業名・代表者名
- 連絡先（電話・メール・SNS DM）
- 現在のSNS状況（フォロワー数・投稿頻度）
- ビジネス内容・ターゲット層
- 予算感・契約期間の希望
```

#### 1-2. Notion「商談ログ」にエントリを作成
1. `context/きっかけLab.SNSマーケ事業/営業管理/商談ログ/` を開く
2. Notion 「商談ログ」DB にアクセス
3. 新規ページを作成し、以下を記入：
   - **顧客名**: クライアント企業名（必須）
   - **日付**: 初期接触日
   - **内容**: どのように接触したか（DM, 紹介, 営業コール等）
   - **ステータス**: 「初期接触」に設定
   - **進捗**: 「新規」に設定
   - **次のアクション**: 初回打合せの日程調整

---

### **ステップ2：商談実施（提案段階）**

#### 2-1. 初回打合せの実施
```
【確認すべきポイント】
- クライアントの課題・ニーズ
- SNS運用の目的（認知拡大 / 売上向上 / ファン構築等）
- 現在の困り事（投稿できない / エンゲージメント低い等）
- 予算・契約期間の詳細
- 意思決定者は誰か
```

#### 2-2. 見積もり・提案資料の作成
1. 打合せ内容を基に、提案資料を作成（2営業日以内）
2. テンプレートを使用：`context/きっかけLab.SNSマーケ事業/営業管理/DMテンプレート/`
3. 見積もり金額は経理責任者に相談
4. 提案資料を顧客に送付

#### 2-3. Notion を更新
- **ステータス**: 「提案中」に変更
- **内容**: 提案日時・提案内容・見積もり金額を記載
- **次のアクション**: 顧客からの返答待ち or 提案フォローアップ日程

---

### **ステップ3：交渉・契約（成約段階）**

#### 3-1. 顧客からのフィードバック対応
```
【よくあるパターン】
- 価格交渉 → 経営者と相談、30%以上の値引きは要承認
- 契約期間の短縮 → 応相談
- サービス内容の変更 → 詳細を聞いて提案資料を修正
```

#### 3-2. 契約書の作成・署名
1. 契約条件が固まったら、契約書を作成
2. 契約金額・開始日・期限を明記
3. 顧客署名後、控えを保管

#### 3-3. Notion を更新
- **ステータス**: 「成約」に変更
- **金額**: 契約金額を記入（必須）
- **内容**: 契約条件・サービス内容を詳細に記載
- **次のアクション**: サービス開始日程・打合せ日程を記入

---

### **ステップ4：サービス開始後（進行管理）**

#### 4-1. 定期的なクライアント対応
- 初回打合せ：サービス内容・SNS運用方針の確認
- 月1回：成果報告・改善提案
- 随時：SNS投稿・問い合わせ対応

#### 4-2. Notion を定期更新
```
【毎月更新する項目】
- 進捗：「進行中」を維持
- 内容：当月の実績・課題・来月の施策を記載
- 次のアクション：翌月の対応を記入

【更新頻度】
- 打合せ後：即座に更新
- 月1回：月間成果を更新
```

#### 4-3. 継続課題の管理
```
【以下の場合は即座に報告・相談】
- クライアントからのクレーム
- 契約内容と異なるリクエスト
- 継続困難な理由が出た場合
```

---

### **ステップ5：月間売上管理**

#### 5-1. 月末に売上を確定
1. Notion「商談ログ」から、当月成約した案件を確認
2. 売上管理表（経理責任者が管理）に情報を提出
3. 請求書を発行（月末-1日まで）

#### 5-2. 売上目標の進捗確認
```
【毎週金曜に確認】
- 当月の成約件数：目標3件に対して何件か
- 当月の売上：目標達成率は何%か
- 来月見込み：現在の商談パイプラインから推計

【目標未達の場合】
- 営業活動を加速（新規DM・営業コール）
- 既存クライアントへのアップセル提案
```

## ❓ よくある質問（FAQ）

### **Q1. 初期接触後、どのくらいで提案資料を作成すべき？**
**A.** 2営業日以内に提案資料を作成・送付するのが目安です。遅れるほど顧客の関心が薄れるため、速度を優先してください。

---

### **Q2. 顧客から値引き要求が来た場合、どうしたらいい？**
**A.** CLAUDE.md の「判断のルール」を参照してください。
- 30%未満の値引き：経理責任者に相談して判断
- 30%以上の値引き：必ず CEO 承認が必須

---

### **Q3. クライアントが返信してこない場合は？**
**A.** 以下の流れで対応してください：
1. 初回メール：1週間待機
2. フォローアップDM：1週間後に送信
3. 電話での確認：さらに3日待機後
4. 終了判定：CEO に報告（失注処理）

---

### **Q4. 契約後、クライアントが満足していない場合は？**
**A.** 以下の対応を取ってください：
1. 詳しく課題をヒアリング
2. サービス内容の改善提案を作成
3. CEO と相談（契約内容変更の可能性）
4. 即座に対応（継続関係を維持）

---

### **Q5. 売上目標が達成できそうにない場合は？**
**A.** 以下のアクションを即座に実施：
1. CEO に進捗報告（現在の見込み売上）
2. 既存クライアントへのアップセル提案
3. 新規営業活動を加速（未接触企業へのDM）
4. 月間最後の1週間で最大の力を注ぐ
