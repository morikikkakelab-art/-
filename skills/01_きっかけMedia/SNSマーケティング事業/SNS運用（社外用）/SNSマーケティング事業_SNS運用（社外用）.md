# SNSマーケティング事業_SNS運用（社外用）

## 1. スキルの概要

### 1.1 目的
クライアント企業のSNSアカウントに対して、プロフェッショナルな動画・テキストコンテンツを企画・制作し、以下を実現します：
- **採用応募の増加** - 職場の空気感・働き方をコンテンツで伝える
- **来店数・問い合わせの増加** - 商品・サービスへの興味を喚起
- **ブランド認知度向上** - 企業の世界観を一貫して発信

### 1.2 対象範囲
- クライアント企業のSNS運用代行
- 4プラットフォーム：Instagram、TikTok、LINE、X
- 3つの事業目的に特化したコンテンツ企画・制作

### 1.3 使用ツール
- **Notion** - コンテンツカレンダー、台本管理
- **動画編集ツール** - Adobe Premiere、CapCut等
- **キャプション・ハッシュタグ分析ツール** - SNSネイティブ機能、Hashtagsなど

## 2. きっかけLab.のコンテンツ戦略

### 2.1 採用特化型
**ターゲット**: 若い世代の求職者
**コンテンツの特徴**: 「働く姿」「職場の空気感」を見せる

**伝えるべき要素：**
- 日々の仕事風景
- チームメンバーのキャラクター
- 働く価値観・企業文化
- キャリア成長のストーリー

---

### 2.2 集客特化型
**ターゲット**: 既存顧客・見込み客
**コンテンツの特徴**: 「行きたい」「また来たい」という感情を喚起

**伝えるべき要素：**
- 商品・サービスの魅力
- 実際の利用シーン
- 顧客満足の声・事例
- 期間限定のキャンペーン情報

---

### 2.3 ブランディング特化型
**ターゲット**: 一般大衆（潜在顧客含む）
**コンテンツの特徴**: 企業の世界観・こだわりを一貫して発信

**伝えるべき要素：**
- ブランドの哲学・価値観
- こだわりの製造工程・素材
- 代表者の想い
- コンテンツとしての芸術性

---

## 3. 各プラットフォームの特性

### 3.1 Instagram（インスタグラム）
**ユーザー層**: 20代〜40代、女性ユーザー比率が高い
**コンテンツ形式**: リール（15秒〜90秒動画）、フィード投稿
**アルゴリズム特性**: エンゲージメント（いいね・保存・シェア）重視
**最適な目的**: 集客特化、ブランディング特化

**コンテンツのポイント：**
- 見た目の美しさ・統一感が重要
- 1話完結で見やすい構成
- 保存したくなる情報量

---

### 3.2 TikTok（ティックトック）
**ユーザー層**: 10代〜30代、若年層が中心
**コンテンツ形式**: ショート動画（15秒〜10分）
**アルゴリズム特性**: 視聴完了率・シェア率・クリエイター属性重視
**最適な目的**: 採用特化、集客特化

**コンテンツのポイント：**
- 最初の3秒で掴む
- 親しみやすい、素の雰囲気
- トレンド音楽・効果音の活用

---

### 3.3 LINE（ライン）
**ユーザー層**: 全年代、ユーザー数が最多
**コンテンツ形式**: ホーム投稿（テキスト＋画像）
**アルゴリズム特性**: フォロー関係によるフィード表示
**最適な目的**: 集客特化（顧客関係構築）

**コンテンツのポイント：**
- テキスト量は少なめ
- 親しみやすさが重要
- CTA（クーポン・予約など）の活用

---

### 3.4 X（エックス、旧Twitter）
**ユーザー層**: 20代〜50代、ビジネスパーソン比率が高い
**コンテンツ形式**: テキスト＋画像・動画
**アルゴリズム特性**: リツイート・リプライ・いいね重視
**最適な目的**: ブランディング特化、採用特化

**コンテンツのポイント：**
- テキストがメイン
- 情報性・議論性が高い内容
- 業界トレンド・ナレッジの発信

## 4. 伸びるコンテンツテーマ集

### 4.1 採用特化型
伸びやすいテーマ：
1. **朝礼・朝活シーン** - チームの絆、モーニングルーティン
2. **社員インタビュー** - 「なぜこの会社で働いているのか」
3. **オフィスツアー** - 職場の環境・設備の紹介
4. **失敗から学んだこと** - 成長ストーリー、ポジティブな失敗談
5. **新人研修・育成の様子** - 教育制度の充実感
6. **社員の日常風景** - 仕事中の工夫・楽しさ
7. **福利厚生・社内制度** - 働きやすさの訴求
8. **キャリアパスの成功例** - 昇進・成長の具体例

---

### 4.2 集客特化型
伸びやすいテーマ：
1. **Before/After** - 商品・サービス利用前後の変化
2. **使い方のコツ・豆知識** - すぐに応用できる情報
3. **顧客の笑顔・満足シーン** - UGC風、ユーザー体験
4. **季節・トレンドに合わせた企画** - 限定感の演出
5. **商品開発の裏側** - こだわり・ストーリー
6. **Q&A形式** - よくある質問への回答
7. **キャンペーン・セール情報** - 期間限定の訴求
8. **顧客の声・レビュー** - 信頼感の構築

---

### 4.3 ブランディング特化型
伸びやすいテーマ：
1. **代表者の想い・ビジョン** - 企業哲学の発信
2. **素材・製造工程へのこだわり** - 品質への信頼感
3. **環境・社会への取り組み** - CSR・サステナビリティ
4. **業界の課題解決への取り組み** - 思想的リーダーシップ
5. **ブランドストーリー・起源** - 企業の背景・成り立ち
6. **社員の多様性・チーム風景** - 組織文化の可視化
7. **実績・受賞歴** - 客観的信頼性

## 5. コンテンツ台本生成フロー

このセクションでは、目的とプラットフォームを指定することで、動画台本・キャプション・ハッシュタグが自動生成される仕組みを提供します。

### 5.1 入力項目

コンテンツ台本を作成する際に、以下の情報を準備してください：

| 項目 | 説明 | 例 |
|-----|------|-----|
| **目的** | 採用特化 / 集客特化 / ブランディング特化 | 採用特化 |
| **プラットフォーム** | Instagram / TikTok / LINE / X | TikTok |
| **テーマ** | コンテンツの具体的なネタ | 「朝礼・朝活シーン」 |
| **企業情報** | 企業名、業種、特徴 | 「〇〇建設、建設業、若手が活躍」 |
| **メインメッセージ** | このコンテンツで最も伝えたいこと | 「このチームは楽しく働いている」 |
| **ビジュアル要素** | 動画に含める主な映像・シーン | 「朝礼風景、スタッフの笑顔、現場作業」 |
| **CTA（Call To Action）** | 視聴後の行動誘導 | 「採用情報をチェック」「DM送信」 |

### 5.3 台本作成時の重要ポイント

✅ **動画台本で必ず含める要素：**

1. **つかみ（最初の3秒）** - 視聴を継続させるための引き込み
2. **メインメッセージ** - このコンテンツで最も伝えたいこと
3. **ビジュアル＋音** - テロップ、BGM、効果音の組み合わせ
4. **CTA** - 視聴後の行動誘導（予約、DM、フォローなど）

✅ **プラットフォーム別のポイント：**

| プラットフォーム | 特に重視すること |
|---------|----------|
| **Instagram** | 映像美しさ、統一感、保存したくなる情報 |
| **TikTok** | 最初の3秒の引き込み、親しみやすさ、トレンド活用 |
| **LINE** | テキスト親しみやすさ、CTA明確性 |
| **X** | テキスト情報性、議論性、シェアされやすさ |

✅ **キャプション作成のコツ：**
- 1行目でビジュアルを言語化する
- 改行を使って読みやすく（特にLINE・X）
- CTA（次のアクション）を明確にする
- 絵文字は適度に使う（親しみやすさ向上）

✅ **ハッシュタグ選定のコツ：**
- メインキーワード3〜5個 + サブキーワード5〜7個
- 検索ボリュームと競合性のバランス
- ブランド固有ハッシュタグも含める

⚠️ **避けるべき表現：**
- 押し売り感のあるCTA（「今すぐ買わないと損！」など）
- 誇大表現・根拠のない主張
- 難しい専門用語（初心者向けなら特に注意）
- 長すぎるテキスト（特にTikTok・Instagram）

### 5.4 生成した台本の検証チェックリスト

実際に制作する前に、以下を確認してください：

**内容面：**
- [ ] メインメッセージが明確に伝わるか
- [ ] CTAが具体的で実行しやすいか
- [ ] ビジュアル要素が目的に合致しているか
- [ ] 対象プラットフォームの特性に合っているか

**構成面：**
- [ ] 最初の3秒で視聴を続けたくなるか
- [ ] 冗長さがなく、テンポよく進むか
- [ ] 動画の長さがプラットフォーム適切か（TikTok: 15秒〜1分、Instagram: 15秒〜90秒等）

**テキスト面：**
- [ ] キャプションは読みやすいか（改行、句読点）
- [ ] ハッシュタグは適切な個数と質か
- [ ] 絵文字は親しみやすいか（過度ではないか）
- [ ] 企業のトーン・ブランドイメージに合致しているか

**CTA面：**
- [ ] 次のアクションが明確か
- [ ] 視聴者が実行しやすいか（リンク、予約方法など）
- [ ] 期限感・緊急性があるか（必要に応じて）

## 6. Notionでの管理

### 6.1 「SNS運用コンテンツカレンダー」データベース

月次の投稿スケジュールとコンテンツ企画を一元管理します。

**プロパティ：**
- コンテンツ名（テキスト）
- 目的（セレクト：採用特化 / 集客特化 / ブランディング特化）
- プラットフォーム（マルチセレクト：Instagram / TikTok / LINE / X）
- テーマ（テキスト）
- 投稿予定日（日付）
- ステータス（セレクト：企画中 / 台本作成中 / 制作中 / 校正中 / 投稿予定 / 投稿済み）
- 担当者（ユーザー）
