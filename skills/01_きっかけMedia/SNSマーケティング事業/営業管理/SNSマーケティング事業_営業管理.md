# SNSマーケティング事業_営業管理

## 1. スキルの概要

### 1.1 目的
- 顧客情報の効率的な管理
- 営業のテンプレ作成
- 商談進捗の可視化
- 売上予測の精度向上

### 1.2 対象範囲
新規リード獲得 → 初回接触 → ヒアリング → 提案 → 契約締結

### 1.3 使用ツール
- **Notion**
  - 顧客データベース
  - 商談管理

## 2. リード管理

### 2.1 リード獲得源の特定
以下の獲得源から見込み客（リード）を特定・分類します：
- Webサイト
- 紹介（既存顧客からの紹介）
- イベント（展示会、セミナーなど）
- SNS（Instagram、TikTok、X など）
- その他

### 2.2 リード情報のNotionデータベース登録
新規リード獲得時に、以下の情報をNotionに登録します：

**登録項目：**
- 会社名
- 担当者名
- 連絡先（電話・メール）
- 獲得日
- 獲得源
- リードステータス（新規、検討中、案件化待ちなど）
- 業種・事業内容
- 企業規模
- 課題・ニーズ（初期情報）

### 2.3 リードの優先順位付け基準
以下の基準に基づいて、リードを優先順位付けします：

| 優先度 | 判定基準 | アクション |
|--------|--------|----------|
| 🔴 高 | 即座にニーズがある、予算確保済み、決定権者がいる | すぐに初回接触を設定 |
| 🟡 中 | 近い将来（3〜6ヶ月）のニーズがある | 定期的なフォローアップを開始 |
| 🟢 低 | ニーズが不明確、検討段階 | リード育成（メール・SNS等）を実施 |

## 3. 営業活動の実行プロセス

このセクションでは、実際の営業活動で使用するテンプレートと進め方を提供します。
各フェーズで「必要な情報を入力 → テンプレートが生成される」という方式を採用しています。

### 3.1 DM営業テンプレート生成フロー

DM営業は、初回接触の最初のステップです。SNSのDMを使用して、見込み客に親しみやすく、かつ商談につながるメッセージを送信します。

#### **入力項目**

DM営業テンプレートを作成する際に、以下の情報を準備してください：

| 項目 | 説明 | 例 |
|-----|------|-----|
| **顧客名** | 企業名または担当者名 | 〇〇株式会社、田中さん など |
| **顧客の業種・事業内容** | 相手の事業内容 | 飲食業、美容業、製造業 など |
| **競合との差別化ポイント** | きっかけLab.が他社と違う理由（最も伝えたいこと） | 「一眼カメラで高品質な世界観を実現」「採用に特化した動画制作」 など |
| **実績** | 具体的な成果（件数、成約率、売上増加など） | 「採用応募30%増」「来店数2倍」 など |
| **CTA（Call To Action）** | 次のアクション | 「30分の無料相談」「カタログ送付」「デモ見学」 など |

#### **テンプレート生成例**

**入力例：**
- 顧客名：ABC飲食グループ（担当者：田中さん）
- 業種：飲食業（カフェチェーン）
- 差別化ポイント：一眼カメラで撮影した高品質な写真で、SNS投稿の反応が激変
- 実績：クライアント企業の来店数が平均150%増加
- CTA：30分の無料戦略相談

**生成されるDM文：**

```
田中さんへ

こんにちは！きっかけLab.の〇〇です。

ABCカフェ、いつも素敵なお店だなと思ってSNSをフォローしていました😊

弊社は、SNS運用 × プロ撮影で、飲食店の「来店数」を増やす会社です。

他のSNS運用会社と違うのは、スマホではなく一眼カメラでプロが毎月撮影すること。
その結果、クライアント企業の来店数が平均150%増加しています。

ABCカフェのような素敵なお店こそ、写真の質で大きく変わると感じています。

ぜひ一度、30分の無料戦略相談をしませんか？
お店の課題を聞いた上で、具体的なアイデアをお伝えします。

都合がつけば、お返事ください！

〇〇
```

#### **DM文章作成時の重要ポイント**

✅ **必ず含める要素：**
1. **会社紹介**（1〜2文で簡潔に）- 何をやっている会社か、その特徴
2. **実績**（具体的な数字）- 信頼性を高める
3. **CTA**（明確な次アクション）- 相手が返信しやすい形で

✅ **トーン・スタイル：**
- 親しみやすい言葉使い（敬語は使うが、堅苦しくない）
- 相手の事業に対する理解・リスペクトを示す
- 押し売り感を出さない

✅ **長さ：**
- 全体で150〜200文字程度（短めに）
- スマホ画面で2〜3行に収まるサイズ

⚠️ **避けるべき表現：**
- 「ぜひ一度、ご検討ください」（押し付け感）
- 「貴社の課題を解決します」（上から目線）
- 長すぎるテンプレート（返信率が下がる）

#### **生成したDMの検証チェックリスト**

生成したDM文を送信する前に、以下を確認してください：

- [ ] 会社紹介が含まれているか
- [ ] 実績が具体的な数字で表現されているか
- [ ] CTAが明確か（返信しやすいか）
- [ ] 文字数は150〜200字か
- [ ] トーンは親しみやすいか（堅すぎないか）
- [ ] 相手の企業名・事業に合わせた内容になっているか
- [ ] 差別化ポイントが伝わっているか

## 4. 商談管理

### 4.1 商談フェーズの定義

| フェーズ | 定義 | 期間目安 |
|---------|------|---------|
| **初回接触** | リードへの初めての接触（DM・電話・メール・面談） | 獲得後1週間以内 |
| **ヒアリング** | 課題・ニーズの詳細を聞き取る | 初回接触後1〜2週間 |
| **提案** | 提案資料を作成し、ソリューションを提示 | ヒアリング後1週間以内 |
| **見積もり・交渉** | 見積もり提示、条件交渉 | 提案後1〜2週間 |
| **契約締結** | 契約書に署名、サービス開始 | 交渉完了後1週間以内 |

### 4.2 各フェーズでのアクション

#### 初回接触後
- Notionに議事録を記録する
- 次回接触予定日を設定する
- 顧客の初期ニーズをメモに記入

#### ヒアリング完了後
- 課題整理シートを作成
- 提案資料作成依頼をクリエイティブ部門に提出
- 顧客ニーズをNotionに詳細記録

#### 提案実施後
- 顧客反応を記録
- 次ステップを明確にする
- 確度を「高」「中」「低」で更新

#### 契約締結後
- 契約内容をNotionに記録
- 経理部門に請求情報を連携
- サービス開始日・内容をNotionで管理

### 4.3 商談情報のNotionデータベース管理

**登録項目：**
- 案件名
- 顧客名
- 担当者名
- 現在のフェーズ
- 次アクション
- 予定日（次の接触予定日）
- 確度（高・中・低）
- 金額（予想売上）
- 議事録・メモ

### 4.4 商談進捗の定期的なレビュー

**週次レビュー（毎週月曜日）:**
- 進捗状況の確認
- 滞留している案件の原因分析
- 次週のアクション計画

**月次レビュー（毎月最後の営業日）:**
- 月間の成約率・受注数を集計
- KPI進捗を確認
- 翌月の売上予測を更新

## 5. 顧客情報管理

### 5.1 顧客情報のNotionデータベース一元管理

**顧客マスターデータベース登録項目：**
- 会社名
- 業種・事業内容
- 企業規模（従業員数、売上規模など）
- 所在地
- 主要な連絡先（複数登録可能）
- 課題・ニーズ
- 過去の提案履歴
- 利用中のサービス・契約内容
- 顧客ランク（重要度分類）

### 5.2 顧客とのコミュニケーション履歴の記録方法

**記録内容：**
- 接触日時
- 接触方法（電話・メール・対面など）
- 接触内容（課題、質問、提案内容など）
- 顧客の反応・意見
- 次回接触予定日
- 担当者メモ

**記録場所：**
- Notionの顧客ページにコメント・タイムラインとして記録
- または、専用の「コミュニケーション履歴」テーブルで管理

## 7. 営業報告・分析

### 7.1 営業活動の報告方法

**週次営業報告：**
- 報告時期：毎週金曜日
- 報告先：経営層（Slackで報告）
- 報告内容：
  - 当週の成約数・金額
  - 商談数・進捗
  - 新規リード獲得数
  - 翌週のアクション予定

**月次営業報告：**
- 報告時期：毎月末
- 報告先：経営層・全社員向け（Notionダッシュボード + Slack通知）
- 報告内容：月次KPI分析（下記参照）

### 7.2 KPI分析項目

以下の指標を毎月集計・分析します：

| KPI | 定義 | 目標・評価 |
|-----|------|----------|
| **新規リード獲得数** | 当月に新規登録されたリード数 | 目標値：TBD件 |
| **商談数** | フェーズが「ヒアリング」以上に進んだ案件数 | 目標値：TBD件 |
| **成約数** | 契約締結に至った案件数 | 目標値：TBD件 |
| **成約率** | （成約数 / 商談数）× 100 | 業界平均：30〜40% |
| **平均単価** | 当月受注金額 / 成約数 | 目標値：TBD円 |
| **月間受注金額** | 当月の総受注金額 | 目標値：TBD円 |
| **営業サイクル** | リード獲得から成約までの平均日数 | 短縮目標：TBD日 |

## 8. 連携（他部門・他スキル）

### 8.1 クリエイティブ部門との連携
- **連携内容**：提案資料作成
- **タイミング**：ヒアリング完了後
- **情報共有**：顧客ニーズ、提案内容、納期要件をNotionで共有
- **成果物**：提案資料、デザイン案

### 8.2 経理部門との連携
- **連携内容**：請求情報、契約金額の連携
- **タイミング**：契約締結時、月次
- **情報共有**：顧客名、契約金額、請求日程、支払い条件
- **成果物**：請求書、契約書

### 8.3 SNS運用チームとの連携
- **連携内容**：顧客情報の共有、SNS施策の連携
- **タイミング**：契約後、定期的
- **情報共有**：顧客のビジネス内容、SNS運用目標、期待効果
- **成果物**：SNS運用レポート（営業フォローアップに活用）
