# SNS運用（社外用）コンテンツ制作ガイドライン

## 0. 前提：社外用とは

**きっかけLab.のクリエイティブ事業が自社SNSで発信する、一般向けの本番コンテンツです。**

- **ターゲット**：一般ユーザー、潜在顧客、クリエイティブに興味を持つ人
- **目的**：クリエイティブの最新トレンド、デザイン知見、業界情報を発信することで、きっかけLab.のブランド価値と専門性を伝える
- **形式**：Instagram、Threads、Xなどで実際に投稿される本番コンテンツ
- **注意**：社内チームを教育するコンテンツではなく、外部の一般向けに「見せるコンテンツ」です

---

## 1. 言葉遣い

### 基本原則
- **初心者でもわかるような言葉を使う**
  - 難しい業界用語や専門用語の使用を避ける
  - どの世代・背景を持つ人でも理解できる表現を心がける

### 用語使用時の注釈ルール
- **必須：初出時に注釈をつける**
  - 例：「UI（ユーザーが画面で目にするデザイン）」
  - 例：「ペルソナ（商品やサービスの理想的な顧客像）」
  
- **複数回使用する場合**
  - 初出時：フル表記＋注釈
  - 2回目以降：略称のみでOK
  - 例：「UI（ユーザーインターフェース）を改善した。その結果、UIの使いやすさが向上した」

### 避けるべき表現
| 難しい用語 | 簡潔な言い換え |
|---------|------------|
| アルゴリズム | 処理の仕組み、計算方法 |
| データドリブン | データに基づいた、数字を根拠にした |
| バイラル | 広がった、拡散した |
| エンゲージメント | ファンとのやり取り、反応 |
| KPI（重要業績評価指標） | 目標達成の測り方、成功の基準 |
| 最適化 | 改善、工夫 |
| シナジー | 相乗効果、組み合わせることでの効果 |
| オーディエンス | 視聴者、読者、フォロワー |

## 2. プラットフォーム別ガイドライン

### Instagram
**特徴**：ビジュアル重視、ストーリー性
- **文字数**：キャプション最大2,200文字（推奨：150～300文字）
- **言葉のトーン**：親しみやすい、会話的
- **構成**：
  1. つかみ（最初の1～2行で目を引く）
  2. ストーリー（体験や気づきを述べる）
  3. 呼びかけ（ハッシュタグ、質問など）

### Threads
**特徴**：Twitter後継、中程度の長さ、対話的
- **文字数**：300～500文字が最適
- **言葉のトーン**：実務的だが親しみやすい
- **構成**：
  1. 簡潔な主張
  2. 背景説明や体験（3～4文）
  3. 結論と呼びかけ

### X（旧Twitter）
**特徴**：短く、反応速度重視、議論的
- **文字数**：140～280文字が最適
- **言葉のトーン**：端的で、反応を促す
- **構成**：
  1. インパクトある一文
  2. 簡潔な説明（1～2文）
  3. 議論や反応を促す質問

## 3. 数値・統計情報の提示ルール

### 初心者向けの説明方法
- **数値はわかりやすく**
  - ❌「ROIが150%向上」
  - ✅「売上が1.5倍になった」

- **パーセンテージの説明**
  - ❌「92.5%削減」
  - ✅「4時間かかっていたものが30分でできるようになった（90%削減）」

- **比較の工夫**
  - 数字だけでなく、日常的な例を添える
  - 例：「1秒あたり1000枚の画像を処理」→「1秒で1000枚＝1秒で書籍50冊分のデータ量」

## 4. コンテンツの構成パターン

### パターン1：初心者向け教科書型
```
【タイトル】何を学べるか、3語以内で
この〇〇、実は××かもしれません📌

【本文】
・ポイント1：簡潔な説明
・ポイント2：実例
・ポイント3：まとめ

【呼びかけ】
コメントで意見をシェアしてください！
```

### パターン2：事例・体験シェア型
```
【タイトル】結果を先に出す
こうしたら上手くいった話👍

【背景】
昔はこんな課題がありました

【実施内容】
だからこんなことを試してみた

【結果】
その結果、こんなになりました

【学び】
みなさんも試してみませんか？
```

### パターン3：反論・気づき型
```
【タイトル】意外な視点を提示
〇〇は実は✕✕ではなく△△では

【通説】
一般的には〇〇とされています

【なぜ違うのか】
でも実は△△だからです（理由3つ）

【提案】
だから〇〇がおすすめです
```

## 5. 画像・ビジュアルの説明文

### 代替テキスト（altテキスト）ルール
- 何が見える画像か、初心者にもわかるように説明
- ❌「デザイン案」
- ✅「温かみのあるピンク色と白を組み合わせたデザイン案。左側に商品の写真、右側に「新商品発売」のテキスト」

### グラフ・データビジュアルの説明
- グラフの読み方を簡潔に説明
- 単位や数値の意味を明記
- 「何が言えるか」を結論として示す

## 6. チェックリスト

投稿前に必ず確認してください：

- [ ] 難しい用語は初出時に注釈がついているか
- [ ] 中学生でも理解できる言葉を使っているか
- [ ] 数値や統計があれば、わかりやすい表現になっているか
- [ ] 文の長さは適切か（1文は30～40文字が目安）
- [ ] 段落分けで読みやすくなっているか
- [ ] 色の説明が必要な場合、文字でも説明しているか（色覚異常への配慮）
- [ ] リンクやハッシュタグは説明的で誤解がないか
