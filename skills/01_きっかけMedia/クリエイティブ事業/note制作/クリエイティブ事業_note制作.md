# クリエイティブ事業_note制作

## 1. スキルの概要

### 1.1 目的
noteを通じて以下を実現します：
- **クリエイティブリテラシー向上** - ビジュアル撮影の基礎知識を発信
- **ブランド認知度向上** - きっかけLab.の撮影哲学・ノウハウを発信
- **リード獲得** - クリエイティブについて学びたい層を見込み客に育成

### 1.2 対象読者
- 自社撮影を改善したい企業（小規模事業者、スタートアップ等）
- クリエイティブに興味のある人（個人事業主、フリーランス、デザイナー等）
- SNS運用でビジュアル改善を考えている層

### 1.3 使用ツール
- **note** - 記事公開プラットフォーム
- **Notion** - 企画、下書き管理
- **その他** - 画像編集ツール等（必要に応じて）

## 2. note記事のテーマ・内容

### 2.1 記事カテゴリー

#### ① 撮影の基礎知識
プロがやっている撮影テクニック、初心者が知っておくべき知識を提供します。

**記事例：**
- 「スマホ撮影 vs 一眼カメラ - 何が違う？初心者向けガイド」
- 「ライティングの基本 - 商品を美しく見せるコツ」
- 「背景選びで写真が劇的に変わる理由」
- 「構図のルール - プロが意識していること」
- 「色温度・ホワイトバランス - 自然な写真の秘密」

#### ② ブランドビジュアル戦略
写真を通じて、ブランド統一感を作る方法を解説します。

**記事例：**
- 「ブランドカラー設計で売上が変わった理由」
- 「世界観統一のためのビジュアルガイドラインの作り方」
- 「色彩心理を使ったクリエイティブ戦略」
- 「一貫性のあるビジュアルがもたらす信頼感」
- 「SNS映えする写真の特徴 - ブランド観点から」

#### ③ 撮影の実践ノウハウ
実際の撮影現場での工夫、失敗事例と対策を共有します。

**記事例：**
- 「撮影予算がない時のアイデア - 工夫で乗り切る」
- 「飲食写真で失敗するパターンと対策」
- 「人物撮影で信頼感を出す5つのコツ」
- 「屋外撮影の課題と解決方法」
- 「撮影データの整理と効果的な活用方法」

#### ④ ビジュアル分析
成功しているビジュアル施策から学べる点を解説します。

**記事例：**
- 「大手企業のビジュアル戦略分析 - 何がうまくいっているのか」
- 「インスタ映えする飲食店写真の共通点」
- 「採用ページで成功している企業の撮影ポイント」
- 「ビフォーアフター事例から学ぶ撮影の威力」
- 「ブランドガイドラインの事例分析」

### 2.2 記事の特徴
- **実践的** - すぐに応用できるテクニック、考え方を提供
- **具体的** - 撮影例、実写真を交えた説明
- **親しみやすい** - 初心者にもわかりやすい言葉遣い
- **信頼できる** - プロの実績に基づく情報

## 3. note記事制作プロセス

### 3.1 企画フェーズ

#### **情報収集**
以下から有用な情報を収集し、記事ネタを探します：

- **撮影トレンド** - 最新の撮影技法、カメラ・機材のアップデート
- **クライアント事例** - 撮影前後での変化、成功ポイント
- **業界事例** - 成功しているブランドのビジュアル戦略
- **顧客からの質問** - クライアントから多く受ける撮影の相談

#### **企画立案**
収集した情報から、記事企画を立案します。

**企画に含める内容：**
- **記事タイトル** - ターゲット層が検索しそうキーワードを含める
- **カテゴリー** - 基礎知識、戦略、実践ノウハウ、分析のいずれか
- **対象読者** - 誰向けの記事か（初心者か、経営層か等）
- **記事概要** - 記事の主旨（100字程度）
- **主要ポイント** - 記事で伝えたい3〜5つの要点
- **参考資料** - 根拠となる撮影事例、成功企業の事例など

#### **企画のNotionへの登録**
企画をNotionの「note企画管理」データベースに登録します。

**登録項目：**
- 記事タイトル
- カテゴリー（基礎知識 / 戦略 / 実践ノウハウ / 分析）
- 対象読者
- 概要
- 主要ポイント
- ステータス（企画中 / 執筆予定 / 執筆中 / 校正中 / 公開予定）
- 公開予定日
- 担当者

### 3.2 執筆フェーズ

#### **構成作成**
企画をもとに、記事の構成（目次）を作成します。

**基本構成：**
1. 導入文（課題設定、記事を読むメリット）
2. 背景解説（撮影の重要性、業界動向など）
3. 本論（3〜5つのポイント、それぞれに写真例や図解）
4. 実践編（すぐに試せるアクション）
5. まとめ・CTA（次のステップへの誘導）

#### **本文執筆**
構成に従って、本文を執筆します。

**執筆時の注意：**
- 初心者にもわかるように、専門用語には説明を付ける
- 実例や撮影写真を交えて、信頼性を高める
- 短い段落で見やすくする（スマホ画面での読みやすさを考慮）
- 能動態を使う、簡潔な表現を心がける
- 一つの文は100字以内にまとめる

#### **画像・図解の追加**
必ず画像を挿入します。

**活用例：**
- 撮影前後の比較写真
- テクニック解説の図解（ライティング図など）
- クライアント事例の写真
- ビジュアルの「良い例」「悪い例」対比

### 3.3 下書き保存フェーズ

#### **Notionへの下書き保存**
執筆が完了したら、Notionの「note下書き」ページに保存します。

**保存内容：**
- 最終タイトル
- 本文（マークダウン形式）
- 画像・図解（ファイルリンク）
- サムネイル画像提案
- 公開予定日

#### **内部リンク・外部リンクの設定**
他のnote記事や参考資料へのリンクを設定します。

### 3.4 品質チェック・校正フェーズ

#### **チェックリスト**
公開前に、以下の項目をチェックします：

**内容・品質面：**
- [ ] タイトルは記事内容を正確に表しているか
- [ ] 対象読者にとって価値のある情報か
- [ ] 主要ポイントが明確に伝わっているか
- [ ] 撮影知識は正確か（プロの視点に基づいているか）
- [ ] 実践的なアクションが含まれているか

**表現・表記面：**
- [ ] 文法的な誤りはないか
- [ ] 専門用語には説明が付いているか
- [ ] 一文が長すぎないか（100字以内）
- [ ] 敬語・表現は適切か
- [ ] 表記ゆれがないか（半角・全角、漢字・ひらがなの統一）

**ビジュアル面：**
- [ ] 画像は記事の説明に適切か
- [ ] 画像サイズは統一されているか
- [ ] 写真の色合いに統一感はあるか
- [ ] 画像のキャプション・説明は明確か
- [ ] 「良い例」「悪い例」の対比は見やすいか

#### **修正対応**
チェックで指摘された項目を修正します。

修正内容は、Notionの下書きページに記録し、最新版を更新します。

### 3.5 FIX・公開予定フェーズ

#### **最終承認**
チェック完了後、管理者が最終確認を実施します。

#### **ステータス更新**
Notionの企画管理データベースで、ステータスを「公開予定」に更新します。

#### **公開スケジュール登録**
noteプラットフォームへの公開スケジュールを設定します。

**設定項目：**
- 公開予定日・時刻
- 記事タイトル
- 記事内容
- サムネイル画像
- タグ（クリエイティブ、撮影、ビジュアル等）

## 4. Notionでの管理

### 4.1 「note企画管理」データベース

企画段階からステータスを管理します。

**プロパティ：**
- 記事タイトル（テキスト）
- カテゴリー（セレクト：基礎知識 / 戦略 / 実践ノウハウ / 分析）
- 対象読者（テキスト）
- 概要（テキスト）
- 主要ポイント（テキスト）
- ステータス（セレクト：企画中 / 執筆予定 / 執筆中 / 校正中 / 公開予定 / 公開済み）
- 公開予定日（日付）
- 担当者（ユーザー）
- リンク（下書きページへのリンク）

### 4.2 「note下書き」テンプレートページ

各記事ごとに下書きページを作成します。

**ページ構成：**
- 記事タイトル
- サムネイル画像提案
- 本文
- 画像・図解（埋め込みまたはリンク）
- 内部リンク・外部リンク一覧
- タグ案
- 修正履歴（コメント）

## 5. note記事の公開スケジュール

### 5.1 公開頻度
- **月2本（隔週）** を目標に公開

### 5.2 公開カレンダー
Notionの「note公開カレンダー」で、3ヶ月分の公開予定を管理します。

### 5.3 SNSへの連動
noteに公開した記事を、SNS（Instagram・X）でも告知します。

## 6. 連携（他部門・他スキル）

### 6.1 クリエイティブ部門との連携
- **連携内容**：撮影事例の提供、記事内画像の高品質化
- **タイミング**：執筆フェーズ
- **情報共有**：記事内容、必要な撮影・図解の仕様をNotionで共有
- **成果物**：高品質な写真・図解

### 6.2 SNS運用チームとの連携
- **連携内容**：公開したnote記事のSNS告知
- **タイミング**：公開当日〜1週間以内
- **情報共有**：公開したnote記事のタイトル・URL、告知文案
- **成果物**：SNS投稿、リード獲得

### 6.3 営業部門との連携
- **連携内容**：クライアントからの撮影相談をnote記事ネタに、公開したnote記事を営業資料として活用
- **タイミング**：定期的
- **情報共有**：顧客からの撮影相談・課題、公開記事のリスト
- **成果物**：営業資料、顧客教育資料

## 7. KPI・効果測定

### 7.1 測定対象
以下のKPIを月次で測定・分析します：

| KPI | 定義 | 目標・評価 |
|-----|------|----------|
| **公開本数** | 当月に公開したnote記事数 | 月2本 |
| **ビュー数** | 各記事の閲覧数 | 1記事あたり目標：TBD |
| **いいね数・スキ数** | 記事に対する読者の反応 | 目標：TBD回 |
| **コメント数** | 記事へのコメント、質問数 | 目標：TBD件 |
| **シェア・リード獲得数** | note経由で得た新規リード数 | 目標：TBD件 |
| **平均滞在時間** | 読者が記事を読んだ平均時間 | 目標：TBD分 |

### 7.2 分析方法
- noteの分析機能でビュー・いいね・コメント数を測定
- Notionのダッシュボードで進捗を管理
- リード獲得源の追跡（note経由の問い合わせ件数）
