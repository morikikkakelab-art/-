# クリエイティブ事業_営業管理

## 1. スキルの概要

### 1.1 目的
- クリエイティブサービス（撮影、ブランドガイドライン設計等）の顧客情報管理
- 営業テンプレート作成による効率化
- 商談進捗の可視化
- クライアントの満足度向上と継続案件獲得

### 1.2 対象範囲
新規リード獲得 → 初回接触 → ブランドヒアリング → 提案 → 撮影開始 → 契約更新

### 1.3 使用ツール
- **Notion**
  - 顧客データベース
  - 商談管理
  - ポートフォリオ・実績管理

## 2. リード管理

### 2.1 リード獲得源の特定
以下の獲得源から見込み客（リード）を特定・分類します：
- Webサイト（ポートフォリオ経由）
- 紹介（既存クライアントからの紹介）
- イベント（展示会、セミナー、ワークショップなど）
- SNS（Instagram、Xなど）
- 営業ＤＭ
- その他

### 2.2 リード情報のNotionデータベース登録
新規リード獲得時に、以下の情報をNotionに登録します：

**登録項目：**
- 会社名
- 担当者名
- 連絡先（電話・メール）
- 獲得日
- 獲得源
- リードステータス（新規、検討中、案件化待ちなど）
- 業種・事業内容
- 企業規模
- クリエイティブニーズ（撮影、ブランドガイドライン、動画制作等）
- 課題・ニーズ（初期情報）

### 2.3 リードの優先順位付け基準
以下の基準に基づいて、リードを優先順位付けします：

| 優先度 | 判定基準 | アクション |
|--------|--------|----------|
| 🔴 高 | 即座にクリエイティブニーズがある、予算確保済み、決定権者がいる | すぐに初回接触を設定 |
| 🟡 中 | 近い将来（3〜6ヶ月）のクリエイティブ案件がある | 定期的なフォローアップを開始 |
| 🟢 低 | ニーズが不明確、検討段階 | リード育成（メール・SNS等）を実施 |

## 3. 営業活動の実行プロセス

このセクションでは、実際の営業活動で使用するテンプレートと進め方を提供します。
各フェーズで「必要な情報を入力 → テンプレートが生成される」という方式を採用しています。

### 3.1 DM営業テンプレート生成フロー

DM営業は、初回接触の最初のステップです。SNSのDMを使用して、見込み客に親しみやすく、かつ商談につながるメッセージを送信します。

#### **入力項目**

DM営業テンプレートを作成する際に、以下の情報を準備してください：

| 項目 | 説明 | 例 |
|-----|------|-----|
| **顧客名** | 企業名または担当者名 | 〇〇株式会社、田中さん など |
| **顧客の業種・事業内容** | 相手の事業内容 | 飲食業、美容業、ファッション など |
| **クリエイティブニーズ** | クライアントが必要としているクリエイティブ課題 | 「毎月の撮影素材が足りない」「ブランドの世界観を統一したい」 など |
| **きっかけLab.の差別化ポイント** | きっかけLab.が他社と違う理由（最も伝えたいこと） | 「一眼カメラでプロが毎月定期撮影」「ブランドガイドライン設計で世界観統一」 など |
| **実績** | 具体的な成果（SNS反応向上、撮影実績など） | 「クライアント企業のInstagram反応が3倍に」「50企業のブランドガイドライン設計」 など |
| **CTA（Call To Action）** | 次のアクション | 「ポートフォリオを見たい」「撮影相談」「ブランドガイドライン設計について話したい」 など |

#### **テンプレート生成例**

**入力例：**
- 顧客名：〇〇カフェ（担当者：佐藤さん）
- 業種：飲食業（カフェチェーン）
- クリエイティブニーズ：毎月のInstagram投稿用に、高品質な写真が必要
- 差別化ポイント：一眼カメラでプロが毎月定期撮影し、世界観を統一
- 実績：クライアント企業のInstagram反応が平均3倍、来店数も150%増加
- CTA：ポートフォリオを見たい、または撮影相談

**生成されるDM文：**

```
佐藤さんへ

こんにちは！きっかけLab.の〇〇です。

〇〇カフェのInstagram、いつも素敵だなと思ってフォローしていました😊

実は、弊社はSNS運用 × クリエイティブ撮影で、飲食店の「来店数」を増やす会社です。

他のクリエイティブ会社と違うのは、単発の撮影ではなく、
一眼カメラでプロが毎月定期的に撮影し、SNS用の素材を継続供給すること。

その結果、クライアント企業のInstagram反応が平均3倍、来店数も150%増加しています。

〇〇カフェのような素敵なお店こそ、プロの撮影でもっと輝くと感じています。

ぜひ一度、弊社のポートフォリオを見てみませんか？
または、30分の撮影相談をしませんか？

お店の撮影課題を聞いた上で、具体的なご提案をさせていただきます。

都合がつけば、お返事ください！

〇〇
```

#### **DM文章作成時の重要ポイント**

✅ **必ず含める要素：**
1. **会社紹介**（1〜2文で簡潔に）- 何をやっている会社か、その特徴（クリエイティブの視点）
2. **実績**（具体的な数字）- 信頼性を高める
3. **CTA**（明確な次アクション）- 相手が返信しやすい形で

✅ **トーン・スタイル：**
- 親しみやすい言葉使い（敬語は使うが、堅苦しくない）
- 相手の事業に対する理解・リスペクトを示す
- クリエイティブの価値を理解している姿勢を見せる
- 押し売り感を出さない

✅ **長さ：**
- 全体で150〜200文字程度（短めに）
- スマホ画面で2〜3行に収まるサイズ

⚠️ **避けるべき表現：**
- 「ぜひ一度、ご検討ください」（押し付け感）
- 「貴社の課題を解決します」（上から目線）
- 長すぎるテンプレート（返信率が下がる）

#### **生成したDMの検証チェックリスト**

生成したDM文を送信する前に、以下を確認してください：

- [ ] 会社紹介が含まれているか（クリエイティブの特徴が明確か）
- [ ] 実績が具体的な数字で表現されているか
- [ ] CTAが明確か（返信しやすいか）
- [ ] 文字数は150〜200字か
- [ ] トーンは親しみやすいか（堅すぎないか）
- [ ] 相手の企業名・事業に合わせた内容になっているか
- [ ] 差別化ポイント（クリエイティブ撮影の価値）が伝わっているか

## 4. 商談管理

### 4.1 商談フェーズの定義

| フェーズ | 定義 | 期間目安 |
|---------|------|---------|
| **初回接触** | リードへの初めての接触（DM・電話・メール・面談） | 獲得後1週間以内 |
| **ブランドヒアリング** | クリエイティブニーズ、ブランド理解、撮影コンセプトを聞き取る | 初回接触後1〜2週間 |
| **提案** | ポートフォリオ・撮影プランを提示し、ビジュアルソリューションを提案 | ヒアリング後1週間以内 |
| **見積もり・交渉** | 撮影費用・納期について提示し、条件を調整 | 提案後1〜2週間 |
| **契約締結** | 契約書に署名、撮影開始スケジュール設定 | 交渉完了後1週間以内 |

### 4.2 各フェーズでのアクション

#### ブランドヒアリング完了後
- ヒアリング内容をNotionに記録
- クライアントのブランド特性・撮影ニーズを整理
- 撮影ガイドライン・コンセプト案をまとめる

#### 提案実施後
- ポートフォリオの反応を記録
- 撮影プランの提案内容をNotionに記録
- 次ステップ（撮影日程など）を明確にする
- 確度を「高」「中」「低」で更新

#### 撮影開始後
- 撮影スケジュール・納期をNotionで管理
- クライアントとの撮影打ち合わせ内容を記録

#### 契約締結後
- 契約内容をNotionに記録
- 撮影スケジュール・納品方法をNotionで共有
- 経理部門に請求情報を連携
- サービス開始日・内容をNotionで管理

### 4.3 商談情報のNotionデータベース管理

**登録項目：**
- 案件名
- 顧客名
- 担当者名
- 現在のフェーズ
- クリエイティブニーズ（撮影、ガイドライン設計等）
- ブランド特性・コンセプト
- 次アクション
- 予定日（次の接触予定日、撮影予定日等）
- 確度（高・中・低）
- 金額（予想売上）
- 議事録・メモ

### 4.4 商談進捗の定期的なレビュー

**週次レビュー（毎週月曜日）:**
- 進捗状況の確認
- 滞留している案件の原因分析
- 撮影スケジュール確認
- 次週のアクション計画

**月次レビュー（毎月最後の営業日）:**
- 月間の成約率・受注数を集計
- 撮影件数・売上実績を確認
- KPI進捗を確認
- 翌月の売上予測を更新

## 5. 顧客情報管理

### 5.1 顧客情報のNotionデータベース一元管理

**顧客マスターデータベース登録項目：**
- 会社名
- 業種・事業内容
- 企業規模（従業員数、売上規模など）
- 所在地
- 主要な連絡先（複数登録可能）
- クリエイティブニーズ（撮影、ガイドライン設計、動画制作等）
- ブランド特性・世界観
- 過去の撮影実績・成果
- 利用中のサービス・契約内容
- 顧客ランク（重要度分類）
- ポートフォリオ参照リンク

### 5.2 顧客とのコミュニケーション履歴の記録方法

**記録内容：**
- 接触日時
- 接触方法（電話・メール・対面など）
- 接触内容（ブランドニーズ、撮影コンセプト、提案内容など）
- 顧客の反応・意見
- 次回接触予定日
- 撮影予定・納期
- 担当者メモ

**記録場所：**
- Notionの顧客ページにコメント・タイムラインとして記録
- または、専用の「コミュニケーション履歴」テーブルで管理

## 7. 営業報告・分析

### 7.1 営業活動の報告方法

**週次営業報告：**
- 報告時期：毎週金曜日
- 報告先：経営層（Slackで報告）
- 報告内容：
  - 当週の成約数・金額
  - 商談数・進捗
  - 新規リード獲得数
  - 撮影スケジュール確認
  - 翌週のアクション予定

**月次営業報告：**
- 報告時期：毎月末
- 報告先：経営層・全社員向け（Notionダッシュボード + Slack通知）
- 報告内容：月次KPI分析（下記参照）

### 7.2 KPI分析項目

以下の指標を毎月集計・分析します：

| KPI | 定義 | 目標・評価 |
|-----|------|----------|
| **新規リード獲得数** | 当月に新規登録されたリード数 | 目標値：TBD件 |
| **商談数** | フェーズが「ブランドヒアリング」以上に進んだ案件数 | 目標値：TBD件 |
| **成約数** | 撮影契約締結に至った案件数 | 目標値：TBD件 |
| **成約率** | （成約数 / 商談数）× 100 | 業界平均：30〜40% |
| **平均単価** | 当月受注金額 / 成約数 | 目標値：TBD円 |
| **月間受注金額** | 当月の総受注金額 | 目標値：TBD円 |
| **営業サイクル** | リード獲得から成約までの平均日数 | 短縮目標：TBD日 |

## 8. 連携（他部門・他スキル）

### 8.1 クリエイティブ部門との連携
- **連携内容**：ポートフォリオ・撮影プラン提案
- **タイミング**：ブランドヒアリング完了後
- **情報共有**：顧客のブランドニーズ、撮影コンセプト、納期要件をNotionで共有
- **成果物**：撮影プロポーザル、参考ビジュアル

### 8.2 経理部門との連携
- **連携内容**：請求情報、契約金額の連携
- **タイミング**：契約締結時、月次
- **情報共有**：顧客名、契約金額、請求日程、支払い条件
- **成果物**：請求書、契約書

### 8.3 SNS運用チームとの連携
- **連携内容**：撮影素材の活用、クライアント情報の共有
- **タイミング**：撮影開始後、定期的
- **情報共有**：クライアントのビジネス内容、撮影コンセプト、配信予定
- **成果物**：SNS投稿（撮影素材活用）、レポート
