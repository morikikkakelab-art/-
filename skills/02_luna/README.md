# Luna責任者スキル

クリエイティブ（撮影・ブランド設計）事業の統括責任者として必要なスキル・知識・実行プロセスをまとめています。

## 🎯 責任者の役割

### コアスキル
- **撮影技術**: 高品質な撮影・カメラワーク
- **ブランド設計**: クライアントに合わせたビジュアルアイデンティティ設計
- **顧客営業**: 案件開拓・関係構築
- **プロジェクト管理**: 撮影案件の納期・品質管理

### 主な業務
- 撮影案件の受注・管理
- ブランド設計コンサルティング
- SNS・プロモーション用素材の撮影
- 月間売上・KPI 管理

## 📊 成功指標（KPI）
- 新規プロジェクト数: 月2件以上
- プロジェクト継続率: 85%以上
- 月間売上: 目標達成
