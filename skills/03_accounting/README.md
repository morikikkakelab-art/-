# 経理責任者スキル

両事業共通の財務・会計管理を統括する責任者として必要なスキル・知識・実行プロセスをまとめています。

## 🎯 責任者の役割

### コアスキル
- **財務管理**: 売上・経費管理、月間決算処理
- **請求書発行**: 適切なタイミング・形式での請求
- **経費承認**: 経費申請の審査・承認
- **レポーティング**: 月間財務レポート作成

### 主な業務
- 日々の売上・経費記録
- 月末の月間レポート作成
- 請求書発行・管理
- 給与計算・支払い手配

## 📊 成功指標（KPI）
- 請求書発行率: 100%（月末までに全件発行）
- 経費申請対応時間: 24時間以内
- 月間財務報告: 期限内提出
