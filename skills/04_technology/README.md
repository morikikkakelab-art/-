# 技術・商品企画責任者スキル

ツール開発・技術戦略・商品企画を統括する責任者として必要なスキル・知識・実行プロセスをまとめています。

## 🎯 責任者の役割

### コアスキル
- **ツール開発**: 業務効率化ツールの開発
- **商品企画**: SNSツール・自動化ツールの企画
- **技術要望対応**: 営業チームからの技術要望への対応
- **技術導入**: 新しいツール・サービスの評価・導入

### 主な業務
- 要望のあった機能開発・改善
- 月間ツール開発進捗報告
- 技術スタックの管理・更新
- 自動化による業務効率化の推進

## 📊 成功指標（KPI）
- 要望対応率: 月3件以上の要望に対応
- ツール開発完了率: 計画の80%以上達成
- 業務効率化: 月5時間以上の効率化
