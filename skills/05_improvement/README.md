# 事業改善責任者スキル

全体事業改善・KPI管理・人材育成を統括する責任者として必要なスキル・知識・実行プロセスをまとめています。

## 🎯 責任者の役割

### コアスキル
- **KPI管理**: 全社KPIの設定・追跡
- **改善施策企画**: データに基づいた改善施策の立案
- **人材育成**: スクール・コミュニティ運営による育成
- **全社連携**: 各部門の課題解決サポート

### 主な業務
- 毎月のKPI確認・分析
- 改善施策の企画・推進
- スクール・コミュニティコンテンツの企画
- 月間改善レポート作成

## 📊 成功指標（KPI）
- KPI達成率: 全社90%以上
- 改善施策実施率: 月3件以上
- スクール・コミュニティ: 月1コンテンツ以上
