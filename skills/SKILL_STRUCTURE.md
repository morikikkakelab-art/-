## 🎯 階層構造の説明

### **第1段階：親スキル（責任者スキル）**

各責任者が持つべき**総合的な能力・役割**を定義します。

**フォーマット：** `【責任者名】/README.md`

**内容：**
- 責任者の役割・権限
- 担当業務の概要
- 月間KPI
- 必要な下位スキル一覧
- 成功指標

**例：** `【1】きっかけLab.責任者/README.md`

---

### **第2段階：子スキル（具体的タスク）**

親スキルを実現するための**具体的なタスク・プロセス**を定義します。

**フォーマット：** `責任者フォルダ/NN_スキル名.md`（NN は01,02,03...の番号）

**内容：**
- タスク説明（何をするのか）
- 実行手順（ステップバイステップ）
- 使用ツール（Notion, Google Drive等）
- チェックリスト
- よくある質問(FAQ)
- 参考リンク

**例：** 
- `【1】きっかけLab.責任者/02_SNS運用.md`
- `【1】きっかけLab.責任者/03_HP記事企画.md`

## 📌 スキル作成のルール

### 1. **ファイル命名規則**
```
NN_スキル名.md

NN = 実行順序を表す番号（01, 02, 03...）
スキル名 = スキル内容を表す日本語（半角アンダースコア区切り）

例：01_営業進捗管理.md, 02_SNS運用.md, 03_HP記事企画.md
```

### 2. **ファイル配置**
```
skills/
├── 【責任者番号】責任者名/ 
│   ├── README.md（親スキル）
│   ├── NN_子スキル名.md（子スキル 複数）
│   └── NN_子スキル名.md
```

### 3. **内容構成（テンプレート）**

各スキルファイルは以下の構成を採用：

```markdown
# スキル名

## 📋 概要
このスキルの目的・背景・重要性

## 🎯 目標
このスキルで達成すべきゴール

## 🔧 実行手順
1. ステップ1
2. ステップ2
3. ステップ3
...

## ✅ チェックリスト
- [ ] 項目1
- [ ] 項目2
- [ ] 項目3

## 🛠️ 使用ツール
- Notion（どのDB？）
- Google Drive（どのフォルダ？）
- その他

## ❓ よくある質問
Q. 質問1
A. 答え1

## 📚 参考リンク
- [CLAUDE.md](../../CLAUDE.md)
- [ファイル構造](../../context/)
```

## 💡 スキル設計のポイント

### ✅ 良いスキル
- **具体的**：誰が見てもやることが明確
- **実行可能**：実際に実行可能な手順を記載
- **段階的**：初心者でも理解できる説明
- **ツール連携**：NotionやGoogleドライブとの連携を明確化

### ❌ 避けるべきスキル
- 抽象的すぎる説明
- 背景や理由ばかりで手順がない
- 実在しないツールの使用
- 実装不可能な要求
