# SNS運用（クライアント + 社内）

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 高  
**習得期間**: 2-3週間  
**実行頻度**: 毎日  
**最終更新**: 2026年5月8日

---

## 📋 概要

SNS運用は、**社内のSNS発信**を毎日自動実行し、**クライアントのSNS成長**は CEO の指示に基づいて実行するスキルです。

**2つの運用軸**を担当します：
1. **社内SNS運用（自動実行）** - きっかけLab.自社のSNS発信・ブランド構築を毎日実行
2. **クライアントSNS運用（CEO指示時のみ）** - CEO からのリクエストに基づいてクライアント支援を実行

毎日の社内投稿を通じてエンゲージメントを拡大し、ブランド認知度を向上させます。

**対象プラットフォーム**: TikTok, Instagram, YouTube, X(旧Twitter), Threads

**ビジョン**: 社内 + クライアントのSNS成長を通じて、きっかけLab.のブランド価値・売上を拡大する

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

### **社内SNS運用（毎日自動実行）**
- ✅ 毎日1投稿以上を確実に実行（TikTok/Instagram/YouTube/X/Threads）
- ✅ 各プラットフォームの特性に合わせた投稿を企画・実行
- ✅ 高エンゲージメント（いいね・コメント・シェア）を獲得する投稿を最適化
- ✅ 月+5%以上のフォロワー増加を実現
- ✅ Notion で投稿スケジュール・成果を一元管理

### **クライアントSNS運用（CEO指示時のみ）**
- ✅ CEO からのリクエストに基づいて、クライアント投稿を実行
- ✅ クライアント別の成果レポートを作成・提供
- ✅ エンゲージメント対応案を Claude に生成させ、CEO が投稿

### **共通**
- ✅ トレンド情報を毎週更新（Notion の参考・ナレッジ管理）
- ✅ 各媒体の特性を踏まえた運用戦略を実装

### **ステップ1：月間投稿計画の作成（社内）**

#### 1-1. 月初に投稿カレンダーを作成
**タイミング**: 毎月初日（1日）  
**所要時間**: 2-3時間  
**対象**: きっかけLab.自社の投稿のみ

1. `context/きっかけLab.SNSマーケ事業/SNS運用/全体コンテンツカレンダー/` を開く
2. テンプレート「月間カレンダー」をコピー
3. 当月の投稿計画を作成

```
【カレンダーに記入する項目】
- 日付 / 曜日
- 投稿内容（テーマ）
- プラットフォーム（TikTok / Instagram / YouTube / X / Threads）
- 投稿時間（各媒体・ターゲット層のゴールデンタイム）
- 優先度（高：必ず投稿 / 中：予定通りで大丈夫）
```

#### 1-2. テーマを決める（トレンド + 常時コンテンツ）
```
【月間テーマの決定】
トレンド情報: 毎週金曜に Notion「参考・ナレッジ管理」を更新
            ↓
            当月の流行キーワード・テーマを選定

常時コンテンツ:
 - SNSマーケティング知識（教育系）
 - きっかけLab.のサービス紹介（自社PR系）
 - 業界ニュース・時事ネタ（時事系）
 - ユーザーとのインタラクション（質問・投票系）
```

#### 1-3. Notion「SNS運用」DB に投稿予定を登録
1. Notion 「SNS運用」DB の「社内投稿」セクションにアクセス
2. 新規エントリを月間投稿数分作成（月30投稿 = 日1投稿想定）
3. 以下を記入：
   - **投稿対象**: 「Instagram」「X」「Threads」「TikTok」「YouTube」から選択
   - **投稿ステータス**: 「企画中」
   - **投稿予定日時**: 当月の投稿予定日
   - **投稿用テキスト**: テーマと概要

### **ステップ2：日々の投稿実行（社内）**

#### 2-1. 毎日の投稿準備
**実行時間**: 朝 8:00-9:00（投稿前の準備）  
**対象**: きっかけLab.自社投稿のみ

```
【朝のチェックリスト】
1. 本日の投稿予定を確認（Notion カレンダー）
2. トレンド・時事ネタを確認（Notion「参考・ナレッジ管理」）
3. 各プラットフォームの現在のフォロワー数を記録
4. 昨日の投稿成果（いいね・コメント数）を確認
```

#### 2-2. 各プラットフォーム別の投稿文・画像を作成
**各媒体の特性に合わせた運用**:

| プラットフォーム | 特性 | 投稿スタイル | 文字数 |
|----------------|------|-----------|---------|
| **TikTok** | ショート動画・トレンド重視 | 15-60秒動画・音声・テロップ | - |
| **Instagram** | ビジュアル重視・ストーリー性 | 画像必須・改行活用・絵文字使用 | 2,200字以内 |
| **YouTube** | 長尺動画・解説型 | 企画・構成・字幕・サムネ | - |
| **X** | リアルタイム性・会話重視 | 短文・ニュース性・リツイート価値 | 280字以内 |
| **Threads** | Instagram との連携・カジュアル | 長文OK・カジュアル・思考共有 | 500字程度 |

```
【投稿文の基本構成】
冒頭：つかみ（3行以内で興味引出）
  ↓
本文：価値提供（実践的な知識・タメになる情報）
  ↓
CTA：行動喚起（いいね・フォロー・コメント促進）
  ↓
ハッシュタグ：5-10個（関連キーワード）※X, Instagram, Threadsのみ
```

#### 2-3. Notion に投稿情報を格納
**投稿予約プロパティに記入**:
- **投稿対象**: 該当プラットフォーム（複数選択可）
- **投稿ステータス**: 「投稿待ち(予約)」
- **投稿予定日時**: 実際の投稿予定時刻（ゴールデンタイム）
- **投稿用テキスト**: 各媒体の文字数制限に合わせたキャプション
- **添付メディア**: 図解画像・動画構成案等を保存

#### 2-4. CEO 確認・投稿実行
1. Notion から投稿データを確認
2. 最終チェック（誤字・内容確認）
3. 各プラットフォームに投稿実行
4. Notion「投稿ステータス」を「公開済み」に変更

### **ステップ3：エンゲージメント対応（CEO指示時のみ）**

#### 3-1. 投稿コメント返信案の作成（Claude 生成）
**実行条件**: CEO からの指示がある場合のみ  
**実行者**: きっかけLab.責任者が Claude に生成させ、CEO が最終確認

1. Notion「SNS運用」DB から返信が必要なコメントをリストアップ
2. コメント内容を Claude に入力
3. Claude が返信案を複数提案
4. CEO が選択・修正して投稿

ユーザーコメント: 「この方法、やってみます！」

【返信案】
案1: 「ありがとうございます🙏 ぜひやってみてください！何か質問があれば、いつでもお気軽にDMください😊」
案2: 「こちらこそありがとうございます！ぜひ試してみて、結果を教えてください💪」
案3: 「嬉しいコメントですね😊 実践の際に質問があれば、フォロー＋DM でお気軽に👍」
```

#### 3-2. DM対応（CEO指示時のみ）
**対応時間**: 24時間以内（CEO 指示時）
**対応者**: CEO が指示 → きっかけLab.責任者が対応
**内容**: 新規営業・案件提案・顧客問い合わせ等

### **ステップ4：週間分析（CEO指示時のみ）**

#### 4-1. 週間投稿成果のサマリー
**実行条件**: CEO からの指示がある場合のみ  
**実行時間**: 毎週金曜 17:00（データ収集は自動）  
**実行者**: きっかけLab.責任者

A: 〇〇について（プラットフォーム：〇〇）
   改善案: 文字が多すぎた / 画像がない / ターゲットに合わなかった
```

## ❓ よくある質問（FAQ）

### **Q1. 社内投稿とクライアント投稿の実行フロー、どう違う？**
**A.** 大きく異なります：

| 項目 | 社内投稿（きっかけLab.） | クライアント投稿 |
|------|----------------------|------------|
| **実行頻度** | 毎日自動実行（1投稿/日） | CEO指示時のみ |
| **投稿決定者** | 責任者（計画に基づいて） | CEO（案件ごとに指示） |
| **投稿時間帯** | 14:00-16:00（固定） | CEO指示に基づく |
| **テーマ** | SNS知識・事例・業界ニュース | クライアントのサービス・商品 |
| **Notion 記録** | SNS運用 DB（社内投稿） | クライアント SNS 運用管理 DB |

---

### **Q2. コメント返信は誰がどうやって対応する？**
**A.** Claude が返信案を生成し、CEO が最終判断します：

```
【フロー】
1. SNS にコメントが届く
   ↓
2. きっかけLab.責任者が Claude に「返信案を3パターン生成して」と指示
   ↓
3. Claude が複数の返信案を提案
   ↓
4. CEO が案を見て選択・修正
   ↓
5. CEO が投稿
```

返信は品質重視のため、自動投稿ではなく CEO 最終確認制です。

---

### **Q3. 投稿時間はいつが最適？**
**A.** プラットフォーム・ターゲット層によって異なります：

```
【一般的なゴールデンタイム】
- TikTok: 朝 8-10時 / 夕方 18-20時 / 夜 20-22時
- Instagram: 朝 7-9時 / 昼 12-13時 / 夜 19-21時
- YouTube: 夕方 17-19時 / 夜 20-22時
- X: 朝 8-10時 / 昼 12-13時 / 夜 20-22時
- Threads: Instagram と同じ（朝7-9時 / 昼12-13時）

【調整方法】
- 最初は上記時間帯で試す
- 2週間後、各プラットフォーム Analytics 確認
- ターゲット層がアクティブな時間帯に変更
```

---

### **Q4. エンゲージメントが低い場合、何をする？**
**A.** 以下の改善策を順番に試す：

```
1️⃣ 画像・ビジュアルを改善（ビジュアル系 → 図解に変更等）
2️⃣ テキストを短く、わかりやすく修正
3️⃣ CTA を明確に（「いいねしてください」→「あなたはどう思いますか？」）
4️⃣ ハッシュタグを見直し（人気キーワード追加）
5️⃣ 投稿時間をずらす（各プラットフォームのゴールデンタイムに合わせ）
6️⃣ テーマを変える（反応薄いテーマ → トレンドに合ったテーマに変更）

💡 Notion「参考・ナレッジ管理」DB でトレンド情報を確認してから投稿テーマを決定
```

---

### **Q5. トレンド情報はどこから集めるの？**
**A.** 複数のチャネルから集めて Notion に集約します：

```
【情報源】
- SNS トレンド：TikTok / Instagram / X / YouTube トレンド欄
- ニュース：Yahoo!ニュース・業界ニュース・まとめサイト
- 検索トレンド：Google トレンド・キーワードプランナー
- 参考データ：競合 SNS・インフルエンサーのコンテンツ

【更新頻度】
毎週金曜 17:00 に Notion「参考・ナレッジ管理」DB を更新
→ 翌週の投稿テーマはこのトレンド情報を元に決定

【記録項目】
- テーマ・キーワード
- どのプラットフォームで流行中か
- ターゲット層の反応
- 参考 URL
```

---

### **Q6. クライアント投稿のリクエストが来たら、どういう流れ？**
**A.** CEO からの指示に基づいて実行します：

```
【フロー】
CEO から「〇〇クライアントの投稿をお願いします」と指示
 ↓
1. リクエスト内容を確認（テーマ・プラットフォーム・日時）
 ↓
2. 投稿文・画像を作成
 ↓
3. CEO に確認してもらう
 ↓
4. CEO の承認後、各プラットフォームに投稿
 ↓
5. Notion「クライアント SNS 運用管理」DB に記録
```

クライアント投稿は CEO の指示がないと実行しません。

### **Q7. 日々の投稿が間に合わない場合は？**
**A.** 以下のアクションをとる：

```
社内投稿（毎日自動実行）が遅れた場合:
 └─ 当日中に投稿（実施時間遅延OK）

対策：
 ├─ 月初に月間投稿計画を全て作成
 ├─ 週初めに投稿文・画像を前もって準備
 ├─ Notion に「投稿待ち(予約)」で事前登録
 └─ 「記事制作・公開」スキルと連携（図解画像の活用）
```
