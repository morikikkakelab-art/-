# SNS運用（クライアント + 社内）

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 高  
**習得期間**: 2-3週間  
**実行頻度**: 毎日  
**最終更新**: 2026年5月8日

---

## 📋 概要

SNS運用は、**クライアントのSNS成長**と**きっかけLab.自社のブランド発信**の2つの軸で、毎日の投稿を通じてエンゲージメントを拡大するスキルです。

**目的**:
- クライアントのフォロワー増加・エンゲージメント向上
- きっかけLab.自社のブランド認知度向上
- 毎日1投稿以上の継続実行
- SNS分析データを基にした改善サイクルの実現

**対象プラットフォーム**: Instagram, X(旧Twitter), Threads

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

- ✅ 毎日1投稿以上を確実に実行（クライアント + 社内合計）
- ✅ 高エンゲージメント（いいね・コメント・シェア）を獲得する投稿を企画
- ✅ SNS分析ツールでデータを把握・改善施策を立案
- ✅ クライアント・自社の双方で月+5%以上のフォロワー増加を実現
- ✅ Notion で投稿を一元管理

---

## 🔧 実行手順

### **ステップ1：月間投稿計画の作成**

#### 1-1. 月初に投稿カレンダーを作成
**タイミング**: 毎月初日（1日）  
**所要時間**: 2-3時間

1. `context/きっかけLab.SNSマーケ事業/SNS運用/全体コンテンツカレンダー/` を開く
2. テンプレート「月間カレンダー」をコピー
3. 当月の投稿計画を作成（以下の内容を含める）

```
【カレンダーに記入する項目】
- 日付
- 曜日
- 投稿内容（テーマ）
- プラットフォーム（Instagram / X / Threads）
- 投稿時間（ターゲット層がアクティブな時間）
- 企業別（クライアントA / クライアントB / きっかけLab.自社）
```

#### 1-2. テーマを決める
```
【よくあるテーマ】
- SNSマーケティング知識（教育系）
- トレンド・最新情報（情報系）
- クライアント成功事例（事例紹介系）
- きっかけLab.のサービス紹介（自社PR系）
- 業界ニュース・時事ネタ（時事系）
- ユーザーとのインタラクション（質問・投票系）
```

#### 1-3. Notion「SNS運用」データベースに投稿予定を登録
1. Notion 「SNS運用」DB にアクセス
2. 新規エントリを作成（月間30投稿 = 日々1投稿想定）
3. 以下を記入：
   - **投稿日**: 予定投稿日
   - **プラットフォーム**: Instagram / X / Threads
   - **投稿内容**: テーマと概要
   - **企業別**: クライアント名 or きっかけLab.
   - **ステータス**: 「企画中」

---

### **ステップ2：日々の投稿実行**

#### 2-1. 毎日の投稿業務フロー
**実行時間**: 9:00-12:00（ターゲット層のアクティブ時間帯）

```
【朝のチェック】
1. 本日の投稿予定を確認（Notion カレンダー）
2. クライアント・自社の最新フォロワー数を記録
3. 昨日の投稿エンゲージメント（いいね・コメント数）を確認
```

#### 2-2. 投稿内容の準備
1. Notion 予定からテーマを確認
2. 投稿文を作成（140-300文字目安）
3. 画像があれば用意（or 記事制作フロー参照）
4. ハッシュタグを5-10個追加

```
【投稿文の構成】
冒頭：つかみ（3行以内で興味引出）
  ↓
本文：価値提供（実践的な知識・タメになる情報）
  ↓
CTA：行動喚起（いいね・フォロー・コメント促進）
  ↓
ハッシュタグ：5-10個（関連キーワード）
```

#### 2-3. 各プラットフォームに投稿
| プラットフォーム | 特性 | 投稿スタイル |
|----------------|------|-----------|
| **Instagram** | ビジュアル重視・ストーリー性 | 画像必須・改行活用・絵文字使用 |
| **X** | リアルタイム性・会話重視 | 短文・ニュース性・リツイート価値 |
| **Threads** | Instagram との連携・カジュアル | 長文OK・カジュアル・思考共有 |

#### 2-4. Notion を更新
- **ステータス**: 「公開済み」に変更
- **投稿時間**: 実際の投稿時刻を記入
- **初期エンゲージメント**: 投稿直後のいいね数を記入

---

### **ステップ3：エンゲージメント対応（毎日）**

#### 3-1. 投稿後24時間以内のコメント対応
**優先順位**:
1. **最優先**: クライアント・フォロワーからのコメント → すべて返信
2. **重要**: ポジティブなコメント → 返信 + いいねで応答
3. **参考**: スパム・関係ない投稿 → スルー or ブロック

```
【コメント返信の例】

ユーザーコメント: 「この方法、やってみます！」
↓
返信: 「ありがとうございます🙏 ぜひやってみてください！何か質問があれば、いつでもお気軽にDMください😊」
```

#### 3-2. DM対応
- **対応時間**: 24時間以内
- **対応者**: クライアント DM → クライアント担当者、自社 DM → きっかけLab. 責任者
- **内容**: クライアント問い合わせ / 案件提案 / サービス相談等

---

### **ステップ4：週間分析（毎週金曜）**

#### 4-1. 週間投稿成果のサマリー
**実行時間**: 毎週金曜 17:00

1. Notion「SNS運用」DB から先週の投稿データを確認
2. 以下を集計：

```
【集計すべき指標】
- 投稿数：目標30投稿 / 月に対して、先週は何投稿か
- 総いいね数：全投稿のいいね合計
- 平均いいね数：1投稿当たりのいいね（投稿数÷総いいね）
- コメント数：クライアント・自社の合計
- フォロワー増加数：先週始まりと先週終わりの差
- エンゲージメント率：（いいね+コメント）÷フォロワー数 ×100
```

#### 4-2. トップパフォーマー投稿の分析
```
【分析項目】
Q: 先週、いいね・コメントが最も多かった投稿は？
A: 〇〇について
   理由: ビジュアル（画像）が目立った / タイムリーなテーマだった / CTA が明確だった

Q: 逆に反応が薄かった投稿は？
A: 〇〇について
   改善案: 文字が多すぎた / 画像がない / ターゲットに合わなかった
```

#### 4-3. CEO への週間報告
- Slack / メールで週間成果をレポート
- 翌週の施策案を提案

---

### **ステップ5：月間分析・改善（毎月末）**

#### 5-1. 月間SNS成果をまとめる
**実行時間**: 月末30日

1. Notion「SNS運用」DB から当月すべての投稿を確認
2. 月間レポートを作成：

```
【月間レポート項目】
- 投稿数：目標30投稿に対して、実績は何投稿か
- 総エンゲージメント：いいね・コメント・シェアの合計
- フォロワー増加率：当月のフォロワー増加% （目標：月+5%）
- トップ5 投稿：最もエンゲージメント高かった投稿
- 反省点・課題：何がうまくいかなかったか
- 来月の施策案：改善提案5項目
```

#### 5-2. プラットフォーム別分析
| プラットフォーム | 指標 | 目標 |
|----------------|------|------|
| Instagram | フォロワー増 / リーチ数 | 月+5% / 月1000リーチ |
| X | リツイート数 / インプレッション | 月100RT / 月2000インプレッション |
| Threads | フォロワー増 / いいね数 | 月+3% / 月500いいね |

#### 5-3. クライアント別レポート作成
各クライアントに対して：
- 当月の投稿数・エンゲージメント
- フォロワー増加数・増加率
- 改善提案・来月の施策

## ❓ よくある質問（FAQ）

### **Q1. クライアントの投稿と社内投稿、どう使い分ける？**
**A.** 以下の基準で分け合う：

| 対象 | 投稿内容 | 時間帯 | 頻度 |
|------|---------|--------|------|
| **クライアント** | クライアントのサービス・知識提供 | 10:00-12:00 | 1-2投稿/日 |
| **社内（きっかけLab.）** | マーケティング知識・事例紹介・PR | 14:00-16:00 | 1投稿/日 |

---

### **Q2. 投稿時間はいつが最適？**
**A.** プラットフォーム・ターゲット層によって異なります：

```
【一般的なゴールデンタイム】
- Instagram: 朝 7-9時 / 昼 12-13時 / 夜 19-21時
- X: 朝 8-10時 / 昼 12-13時 / 夜 20-22時
- Threads: Instagram と同じ（朝7-9時 / 昼12-13時）

【調整方法】
- 最初は上記時間帯で試す
- 2週間後、インサイト確認
- ターゲット層がアクティブな時間帯に変更
```

---

### **Q3. エンゲージメントが低い場合、何をする？**
**A.** 以下の改善策を順番に試す：

```
1️⃣ 画像・ビジュアルを改善（ビジュアル系 → 図解に変更等）
2️⃣ テキストを短く、わかりやすく修正
3️⃣ CTA を明確に（「いいねしてください」→「あなたはどう思いますか？」）
4️⃣ ハッシュタグを見直し（人気キーワード追加）
5️⃣ 投稿時間をずらす（ターゲット層のアクティブ時間に合わせ）
6️⃣ テーマを変える（反応薄いテーマ → 反応高いテーマに変更）
```

---

### **Q4. クライアントから「もっと投稿頻度を上げてほしい」と言われたら？**
**A.** 以下の対応をする：

```
1. 現在の投稿頻度（1日X投稿）を説明
2. その理由（品質維持・エンゲージメント最適化）を説明
3. 質の落ちない範囲での増加を提案
4. 契約内容の変更が必要か経理責任者と相談
```

---

### **Q5. 日々の投稿が間に合わない場合は？**
**A.** 以下のアクションをとる：

```
緊急度の判定:
 ├─ クライアント投稿が遅れた → 即座に補填投稿
 ├─ 社内投稿が遅れた → 当日中に投稿（実施時間遅延OK）
 └─ 両方遅れた → CEO に報告

対策：
 ├─ 週初めに投稿文をまとめて準備する
 ├─ 画像は前月中に準備
 ├─ 「記事制作・公開」スキルと連携（図解画像の活用）
```
