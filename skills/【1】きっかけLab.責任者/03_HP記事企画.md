# HP記事企画

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 高  
**習得期間**: 1-2週間  
**実行頻度**: 週1回以上  
**最終更新**: 2026年5月8日

---

## 📋 概要

HP記事企画は、きっかけLab.のホームページに掲載するコンテンツ記事を企画・提案するスキルです。

**目的**:
- SEO キーワード調査に基づく記事企画
- ターゲット層に価値ある記事を企画
- CEO との企画・承認フローの確立
- 月間記事投稿目標（4記事以上）の達成

**対象記事**:
- SNSマーケティング知識・実践例
- ブランド構築ノウハウ
- インスタグラム・X など、プラットフォーム別の運用ガイド
- 業界トレンド・最新事例紹介

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

- ✅ SEO 対策を考慮した記事キーワード・テーマを抽出
- ✅ ターゲット層に響く企画案を複数提案
- ✅ CEO 承認前提案から承認までのプロセスを管理
- ✅ 月間4記事以上の企画を提案・承認を取得
- ✅ 記事制作チーム（執筆者）への詳細指示を作成

---

## 🔧 実行手順

### **ステップ1：リサーチ・キーワード抽出**

#### 1-1. SEO キーワード調査
**実行時間**: 1-2時間（1企画当たり）

1. **Google トレンド確認**
   - Google Trends を開く
   - SNSマーケティング関連キーワード（例：「Instagram 運用」「X(Twitter) 運用」「TikTok マーケティング」等）を検索
   - 過去12ヶ月間のトレンド推移を確認

2. **Google キーワードプランナー確認**
   - キーワードプランナーで月間検索数を調査
   - 検索ボリューム 1000-10000 の中程度キーワードを選定
   - 競争度が「低～中」のキーワードを優先

3. **競合記事分析**
   - 候補キーワードで Google 検索
   - 上位 5-10 件の競合記事をチェック
   - **確認項目**:
     - 記事の構成・フォーマット
     - どのような内容が盛り込まれているか
     - 情報の新しさ（古い情報なら新しい角度で作成可能）
     - ユーザーコメント・評価

#### 1-2. 自社の知見・事例の整理
1. これまでのクライアント成功事例から学習可能な事例をリストアップ
2. よくあるクライアント質問・相談内容を洗い出し
3. SNS運用で得た知見をまとめる

```
【例】
質問: 「Instagram で投稿してもエンゲージメントが低い」
回答: 「投稿時間・ビジュアル・CTA の3つが重要」
→ この内容を基に「Instagram エンゲージメント向上ガイド」記事を企画
```

#### 1-3. 企画候補の一覧化
Notion「HP記事企画」DB に以下をリストアップ：
- キーワード（SEO 対象）
- 記事タイトル案（複数）
- 対象ターゲット層
- 記事概要（100字以内）
- 競合との差別化ポイント
- 参考リンク・資料

---

### **ステップ2：企画案の作成・CEO提出**

#### 2-1. 企画案フォーマットの作成
**実行時間**: 1-2時間（1企画当たり）

企画案に含める項目：

```
【企画案テンプレート】

1. 記事タイトル（SEO キーワード含む）
   例：「Instagram エンゲージメント向上ガイド｜投稿時間・ビジュアル・CTA の最適化」

2. SEO キーワード（ターゲットする検索キーワード）
   - メインキーワード（検索ボリューム×××回/月）
   - サブキーワード（例：「Instagram 投稿時間」「ビジュアル テンプレート」）

3. 対象ターゲット層
   - ペルソナ（例：SNS 初心者企業、フォロワー 1000-5000 程度の企業）
   - 悩み・ニーズ（例：「投稿しても反応がない」「何を投稿すればいいかわからない」）

4. 記事概要（導入）
   - 冒頭で読者の課題・悩みを明確化
   - 記事を読むことで得られるメリット を3つ記載

5. 記事構成（見出し案）
   例：
   ├ 導入：Instagram エンゲージメント が低い理由3つ
   ├ 対策1：投稿時間の最適化（ゴールデンタイム）
   ├ 対策2：ビジュアルの工夫（画像テンプレート例）
   ├ 対策3：CTA（行動喚起）を明確にする
   ├ 実例：〇〇企業の成功事例
   └ まとめ：実装チェックリスト

6. 競合との差別化ポイント
   - 他の記事にない独自情報
   - 自社クライアント事例の活用
   - 実装可能なチェックリスト・テンプレート付き

7. 想定される記事の長さ・ボリューム
   - 短編（2000字以内）
   - 標準編（2000-3500字）
   - 完全ガイド（3500字以上）

8. 参考リンク・出典
```

#### 2-2. 企画案を Notion に登録
1. Notion「HP記事企画」DB を開く
2. 新規エントリを作成
3. 上記フォーマットを記入
4. **ステータス**: 「CEO 承認待ち」に設定
5. **優先度**: 「高」「中」「低」から選択

#### 2-3. CEO に企画案を提出
**提出方法**: Slack / メール
**提出内容**: 企画案フォーマット（Notion リンク含む）
**期待応答**: 3営業日以内に CEO からのフィードバック

```
【提出例】

件名：HP記事企画案提出：「Instagram エンゲージメント向上ガイド」

本文：
以下の企画案を提出いたします。

【企画概要】
タイトル：Instagram エンゲージメント向上ガイド
対象ターゲット：SNS 初心者企業（フォロワー 1000-5000）
SEO キーワード：Instagram エンゲージメント向上（月間1500回検索）

詳細は Notion リンク [ここに DB リンク] をご確認ください。
ご意見・修正案をお願いいたします。
```

---

### **ステップ3：CEO フィードバック対応**

#### 3-1. CEO からのフィードバック確認
CEO からのフィードバック内容を確認：
- 承認 → 記事制作へ進む
- 修正要望 → ステップ3-2へ
- 却下 → 理由確認 → 別の企画案へ

#### 3-2. 修正対応（修正要望の場合）
CEO からのフィードバック例と対応：

```
【フィードバック例】
CEO: 「このキーワードではなく、『X マーケティング 初心者』に変更してほしい」
対応: 
 1. キーワードを「X マーケティング 初心者」に変更
 2. 記事構成を X プラットフォーム向けに修正
 3. 再提出（「修正版」と明記）
 4. CEO 再確認

【修正のポイント】
- CEO の指摘内容を正確に理解する（不明な点は質問）
 - 修正内容を明記して再提出（「修正版 v2」など）
 - 修正期限は原則 24 時間以内
```

#### 3-3. CEO 承認・記事制作へ
CEO からの承認メール確認後：
1. Notion「HP記事企画」DB の**ステータス**: 「CEO 承認済み」に変更
2. 「記事制作」タスクを「05_記事制作・公開」スキルへ依頼
3. 記事制作スケジュールを Notion「全体コンテンツカレンダー」に登録

---

### **ステップ4：CEO 承認待ちの管理**

#### 4-1. 承認待ちの進捗確認
**確認頻度**: 毎週月曜・木曜

1. Notion「HP記事企画」DB から「CEO 承認待ち」のエントリを確認
2. 提出からの経過日数を確認：
   - 3営業日以内 → 通常対応待ち
   - 3営業日以上 → CEO に進捗確認メールを送信

```
【進捗確認メール例】

件名：【確認】HP記事企画案「〇〇」の進捗について

本文：
先日提出いたしました企画案「〇〇」について、ご確認いただけていますでしょうか？
進捗状況をお聞かせください。
[Notion リンク]
```

#### 4-2. 承認状況の一覧管理
毎週末に以下を確認：
- 承認済み企画数
- 承認待ち企画数
- 修正中企画数
- 月間目標達成予測（目標4企画以上）

## ❓ よくある質問（FAQ）

### **Q1. どんなキーワードを選べばいい？**
**A.** 以下の基準で選定してください：

```
✅ 良いキーワード
- 月間検索ボリューム 500-10,000（ニッチすぎず、競合も適度）
- 自社が専門知識を持っているテーマ
- クライアントの悩み・課題と合致するテーマ
- 「〇〇 方法」「〇〇 ガイド」など、ユーザーが情報を求めているキーワード

❌ 避けるべきキーワード
- 月間検索100未満（検索されない）
- 自社の専門外のテーマ
- 巨大企業が独占しているキーワード（例：「Apple」）
```

---

### **Q2. 競合記事にはない差別化ポイント、どう作る？**
**A.** 以下の方法で差別化します：

```
1. 自社クライアント事例の活用
   → 「〇〇という課題を抱えていた〇〇企業が、当社のサポートで月+50%のエンゲージメント達成」

2. 実装可能なチェックリスト・テンプレート
   → 記事を読んだ後、すぐに実装できるテンプレート・チェックリスト付き

3. 業界動向を踏まえた最新情報
   → 記事執筆時点での最新プラットフォーム仕様・アルゴリズム変化を反映

4. わかりやすい図解画像
   → 複雑な概念を図解で説明（「05_記事制作・公開」スキルで実装）
```

---

### **Q3. CEO からの修正要望、何回までやればいい？**
**A.** 原則として**無制限に対応**します。ただし、以下の点に注意：

```
- 修正指示が曖昧な場合は、CEO に質問して正確に理解
- 修正対応は 24 時間以内を目安に（相談可能）
- 複数回の修正を経た場合、修正内容のサマリーを CEO に提出
```

---

### **Q4. 企画案が却下された。どうしたらいい？**
**A.** 以下の対応をしてください：

```
1. CEO に却下理由を確認
   「どのような視点で却下いただきましたか？」

2. 他の企画案を提案
   → 新しいキーワード・テーマで企画案を作成
   → フィードバックを参考に改善

3. 記録に残す
   → Notion「HP記事企画」DB の「却下理由」に記載
   → 今後の企画に活かす
```

---

### **Q5. 月間4記事の目標に間に合いそうにない**
**A.** 以下のアクションをとってください：

```
1. 現在の進捗を CEO に報告
   「現在承認済み企画は2件です。月内に確認可能な企画案はありますか？」

2. 企画案作成を加速
   → 既に候補がある場合は、急いで企画案を完成させる
   → CEO への提出優先度を「高」に上げる

3. CEO と相談
   → 必要に応じて翌月への延期相談
   → 別のコンテンツ形式（note 記事等）の代替検討
```
