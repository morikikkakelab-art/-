# note記事企画

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 高  
**習得期間**: 1-2週間  
**実行頻度**: 週1回以上  
**最終更新**: 2026年5月8日

---

## 📋 概要

note記事企画は、note プラットフォームに掲載するコンテンツ記事を企画・提案するスキルです。

**目的**:
- note 独自のトーン・フォーマットに合わせた企画
- ターゲット読者（ビジネスパーソン・起業家・マーケター）に響く記事企画
- CEO との企画・承認フロー の確立
- 月間記事投稿目標（4記事以上）の達成

**note の特性**:
- **トーン**: 親近感・信頼感・深い思考を重視
- **フォーマット**: 個人の視点・経験・ノウハウシェア
- **読者**: ビジネスパーソン・起業家・独立人・マーケター
- **コンテンツ**: マガジン形式・有料・無料記事の混在

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

- ✅ note プラットフォームの特性を理解した企画立案
- ✅ note 独自のトーン・文体で企画案を作成
- ✅ ターゲット読者層（ビジネスパーソン層）に響く企画を提案
- ✅ CEO 承認前提案から承認までのプロセスを管理
- ✅ 月間4記事以上の企画を提案・承認を取得
- ✅ マガジン・有料記事の活用を検討できる

## 🔧 実行手順

### **ステップ1：note プラットフォーム・トレンド調査**

#### 1-1. note の人気記事・トレンド確認
**実行時間**: 1-2時間（1企画当たり）

1. **note トレンド確認**
   - note ホーム画面の「新着」「人気」タブで確認
   - SNSマーケティング・ビジネス・マーケティング 関連カテゴリを確認
   - スキ数・コメント数が多い記事の傾向を分析

2. **競合・参考アカウント確認**
   - SNSマーケティング関連の著者・アカウントをフォロー
   - 参考になる記事構成・トーン・内容を研究
   - 人気記事の共通特性を抽出

3. **ターゲット読者の悩み・関心事の理解**
   ```
   【note の読者層の特性】
   - ビジネスパーソン・起業家
   - 自分のキャリア・スキルアップに関心
   - 「本質」「実践」「ノウハウ」を求めている
   - 時間をかけて深く読む傾向
   
   【よくある悩み】
   - SNS 運用をしたいが、何から始めればいいか
   - Instagram / X / TikTok など、プラットフォーム別の運用ノウハウ
   - 自分のブランド構築・コンテンツ戦略
   - 副業・個人ブランド化
   ```

#### 1-2. 企画テーマの候補出し
自社の知見・クライアント事例から、note に適したテーマを抽出：

```
【note に適した企画テーマ例】

1. 「フォロワー 3000 から 10000 に増やした秘訣」（実体験）
2. 「Instagram の投稿分析から学ぶ、ハイエンゲージメント投稿の作り方」
3. 「個人ブランド構築の 5 ステップ」（実践ガイド）
4. 「SNS マーケティングで失敗しないための 10 の課題と対策」
5. 「クライアント企業のケーススタディ：課題→施策→成果」

【避けるべきテーマ】
- 一般的すぎてオリジナリティがない
- 自社の実績・事例がないテーマ
- HP 記事と完全に同じ内容
```

#### 1-3. 企画候補の一覧化
Notion「note記事企画」DB に以下をリストアップ：
- テーマ（note 読者に響くテーマ）
- 記事タイトル案（複数）
- 対象ターゴット読者（起業家 / マーケター / ビジネスパーソン等）
- 記事概要（100字以内）
- 自社の差別化ポイント（実績・事例・ノウハウ）
- note の「スキ」を獲得するための工夫
- 参考リンク・競合記事

---

### **ステップ2：企画案の作成・CEO提出**

#### 2-1. note 独自の企画案フォーマット作成
**実行時間**: 1-2時間（1企画当たり）

企画案に含める項目：

```
【企画案テンプレート】

1. 記事タイトル（note 読者の興味を引く表現）
   例：「フォロワー 3 倍に増やせた Instagram 運用の秘訣 ー失敗から学んだ 5 つの原則」
   
   💡 ポイント：
   - 数字を入れる（3倍、50%、5つ等）
   - 「失敗→学び」「課題→解決」のストーリー性を持たせる
   - 読者が「読みたくなる」タイトル

2. リード（導入文）
   - なぜこのテーマを選んだのか（著者の背景）
   - このテーマが「今」重要な理由
   - 読者がどのような状態なのか（課題・悩み）
   - 記事を読むことで得られるメリット

3. 記事のストーリー構成
   例：
   ├ 背景：私が Instagram 運用で失敗していた時期
   ├ 課題：フォロワーが増えず、エンゲージメントも低かった
   ├ 転機：ある「気づき」をきっかけに施策を変更
   ├ 実行：5つの原則を実装
   │ 原則1：投稿時間の最適化
   │ 原則2：ビジュアルの統一
   │ 原則3：CTA（行動喚起）の工夫
   │ 原則4：コメント返信の迅速性
   │ 原則5：トレンド・テーマの活用
   ├ 成果：3ヶ月でフォロワー 3 倍達成
   └ まとめ：あなたも実装できる 5 つの原則

4. 対象読者とメリット
   - ペルソナ（例：SNS 初心者マーケター、フォロワー 1000 程度）
   - この記事で解決できる悩み・課題
   - 実践後の期待成果

5. note 特有の工夫・差別化
   - リアルな失敗体験・ストーリー（数字なし）
   - クライアント事例・ケーススタディ
   - 読者の「スキ」を獲得するための心理的工夫
   - 記事内のビジュアル・段落構成の工夫

6. 有料・マガジン化の検討
   - 無料記事か有料記事か
   - マガジンに含めるか（既存マガジン or 新規マガジン）
   - 期待する「スキ」「コメント」数

7. 想定される記事の長さ・読了時間
   - 短編（5-10分読了：2000-3000字）
   - 標準編（10-15分読了：3000-5000字）
   - 完全ガイド（15-20分読了：5000字以上）

8. 参考リンク・出典
```

#### 2-2. 企画案を Notion に登録
1. Notion「note記事企画」DB を開く
2. 新規エントリを作成
3. 上記フォーマットを記入
4. **ステータス**: 「CEO 承認待ち」に設定
5. **優先度**: 「高」「中」「低」から選択
6. **テーマカテゴリ**: 「SNSマーケティング」「ブランド構築」等から選択

#### 2-3. CEO に企画案を提出
**提出方法**: Slack / メール
**提出内容**: 企画案フォーマット（Notion リンク含む）
**期待応答**: 3営業日以内に CEO からのフィードバック

```
【提出例】

件名：note 記事企画案提出：「フォロワー 3 倍達成のストーリー」

本文：
以下の企画案を提出いたします。

【企画概要】
タイトル：フォロワー 3 倍に増やせた Instagram 運用の秘訣
テーマ：実体験をベースにした Instagram 運用ガイド
対象読者：SNS マーケター初心者（フォロワー 1000-5000）
期待成果：「スキ」「コメント」数の増加・マガジン購読者の拡大

詳細は Notion リンク [ここに DB リンク] をご確認ください。
ご意見・修正案をお願いいたします。
```

---

### **ステップ3：CEO フィードバック対応**

#### 3-1. CEO からのフィードバック確認
CEO からのフィードバック内容を確認：
- 承認 → 記事制作へ進む
- 修正要望 → ステップ3-2へ
- 却下 → 理由確認 → 別の企画案へ

#### 3-2. 修正対応（修正要望の場合）
CEO からのフィードバック例と対応：

```
【フィードバック例】
CEO: 「個人の体験談も大事ですが、クライアント事例も含めてほしい」
対応:
 1. クライアント事例セクションを追加
 2. ストーリー構成を修正（個人体験 + クライアント事例 の並列構成）
 3. 記事の長さを調整（5000字以上に）
 4. 再提出（「修正版」と明記）
 5. CEO 再確認

【修正のポイント】
- CEO の指摘内容を正確に理解する
- note の「スキ」を獲得するための工夫を提案
- 修正期限は原則 24 時間以内
```

#### 3-3. CEO 承認・記事制作へ
CEO からの承認メール確認後：
1. Notion「note記事企画」DB の**ステータス**: 「CEO 承認済み」に変更
2. 「記事制作」タスクを「05_記事制作・公開」スキルへ依頼
3. 記事制作スケジュールを Notion「全体コンテンツカレンダー」に登録

---

### **ステップ4：CEO 承認待ちの管理**

#### 4-1. 承認待ちの進捗確認
**確認頻度**: 毎週月曜・木曜

1. Notion「note記事企画」DB から「CEO 承認待ち」のエントリを確認
2. 提出からの経過日数を確認：
   - 3営業日以内 → 通常対応待ち
   - 3営業日以上 → CEO に進捗確認メールを送信

#### 4-2. 承認状況の一覧管理
毎週末に以下を確認：
- 承認済み企画数
- 承認待ち企画数
- 修正中企画数
- 月間目標達成予測（目標4企画以上）

## ❓ よくある質問（FAQ）

### **Q1. note の企画、HP 記事とどう差別化する？**
**A.** note と HP では、対象読者・トーン・フォーマットが異なります：

```
【HP 記事】
- 対象：SNS 初心者企業、実装ガイドを求めている
- トーン：教育的・網羅的・SEO 最適化
- フォーマット：見出し・リスト・図解重視
- 例：「Instagram エンゲージメント向上の 5 つの施策」

【note 記事】
- 対象：マーケター・起業家・個人ブランド化希望者
- トーン：個人視点・ストーリー・深思考
- フォーマット：体験談・失敗→成功のナラティブ
- 例：「フォロワー 3 倍達成までの、失敗と学びの記録」

【差別化】
note = HP とは異なる読者層に向けた「個人の声」「ストーリー性」
```

---

### **Q2. note で「スキ」「コメント」を増やすコツは？**
**A.** 以下の要素を意識して企画を立案：

```
1. タイトルに感情を込める
   ❌ 「Instagram 運用ガイド」
   ✅ 「フォロワー 3 倍達成のストーリー ー失敗から学んだ秘訣」

2. 冒頭で引き込む
   - 「実は私も同じ悩みを持っていました」
   - 読者の共感を引き出す

3. ストーリー性を持たせる
   - 背景 → 課題 → 転機 → 実行 → 成果
   - 単なる「ノウハウ」ではなく「体験」を語る

4. 途中で「小見出し」を挿入
   - 読みやすさを向上
   - 「ここまで読みたい」という心理を作る

5. 最後にメッセージを込める
   - 読者への投げかけ・問い
   - コメントを促す
```

---

### **Q3. 有料記事にするか無料記事にするか、どう判断する？**
**A.** 以下の基準で判断：

```
【無料記事が向いている】
- 認知拡大が目的
- 新規フォロワー・読者の獲得
- 基本的なノウハウ・入門ガイド
- 「スキ」数の最大化が目的

【有料記事が向いている】
- 深い実践ノウハウ・ケーススタディ
- 自社クライアント企業の成功事例（詳細）
- 戦略レベルのコンサルティング視点
- 月間「購読」「マガジン購読」数の増加が目的

💡 推奨：
最初は無料記事で「スキ」「フォロワー」を増やし
シリーズ化して有料化する流れ
```

---

### **Q4. 企画案が却下された場合、どうする？**
**A.** 以下の対応をしてください：

```
1. CEO に却下理由を確認
   「どのような視点で却下いただきましたか？」

2. フィードバックを整理
   - テーマ選定の失敗か
   - ストーリー構成の失敗か
   - note の特性理解の不足か

3. 次の企画案を提案
   → CEO の意見を反映させた新企画
   → 異なるアプローチでの企画案

4. 記録に残す
   → Notion「note記事企画」DB の「却下理由」に記載
   → 今後の企画に活かす
```

---

### **Q5. 月間4記事の目標に間に合いそうにない**
**A.** 以下のアクションをとってください：

```
1. 現在の進捗を CEO に報告
   「現在承認済み企画は2件です。月内に確認可能な企画案はありますか？」

2. シリーズ化を検討
   → 1テーマを複数の記事に分割
   → 「Instagram 運用の失敗と学び（全3部構成）」など

3. CEO と相談
   → 必要に応じて翌月への延期相談
   → 別のコンテンツ形式の代替検討
```
