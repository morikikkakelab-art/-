# KPI分析・改善

**スキル分類**: きっかけLab.責任者 → 子スキル  
**優先度**: ⭐ 中  
**習得期間**: 1-2週間  
**実行頻度**: 月1回（月末）+ 随時  
**最終更新**: 2026年5月8日

---

## 📋 概要

KPI分析・改善は、きっかけLab.の事業全体（営業・SNS・コンテンツ制作）の月間成果データを集計・分析し、課題を抽出、翌月以降の改善施策を立案するスキルです。

**目的**:
- 月間 KPI 達成度を正確に把握
- 成功事例・失敗事例から改善施策を抽出
- CEO・全社への月間報告書を作成
- データに基づいた意思決定を実現
- 年間目標達成への進捗管理

**対象 KPI**:
- **営業**: 新規クライアント数、売上目標達成率
- **SNS**: 投稿数、フォロワー増加率、エンゲージメント率
- **コンテンツ**: 記事投稿数、記事 PV・スキ数
- **全体**: 月間売上、クライアント継続率

---

## 🎯 目標

このスキルを習得すると、以下ができるようになります：

- ✅ 複数の KPI データを一元集計・管理
- ✅ データ分析から課題・原因を抽出
- ✅ 改善施策を複数提案・優先順位付け
- ✅ CEO 月間報告書を作成・提出
- ✅ データに基づいた意思決定をサポート
- ✅ 年間目標達成への進捗を可視化

### **ステップ2：データ分析・課題抽出**

#### 2-1. プラットフォーム別の成果分析
**実行時間**: 2-3時間（月末）

各SNSプラットフォームの成果を比較・分析：

```
【分析フレームワーク】

Q1: 当月、最もパフォーマンスが良かったプラットフォームは？
A: Instagram（エンゲージメント率 5.2%、フォロワー+150）

Q2: なぜ Instagram が高いのか？理由は？
A: 
 - 投稿テーマ「フォロワー増加ガイド」がターゲット層に合致
 - ビジュアル（図解画像）が統一され、ブランドイメージ向上
 - 投稿時間が適正（PM 14:00-16:00 ゴールデンタイム）

Q3: 逆に、改善が必要なプラットフォームは？
A: YouTube（エンゲージメント率 3.2%、フォロワー+80）

Q4: なぜ YouTube の成果が低いのか？
A:
 - 動画企画（12本）がテキストコンテンツ中心で、YouTube 向き不適切
 - サムネイル・タイトルに工夫がない
 - 公開後の SNS シェア・プロモーションが不足

【改善案】
 →「YouTube 動画企画の見直し」を翌月施策に追加
```

#### 2-2. コンテンツ別の成果分析
**実行時間**: 1-2時間（月末）

投稿内容別に、どのテーマが成果を上げたか分析：

```
【分析項目】

【高パフォーマンス記事】
記事：「Instagram エンゲージメント向上ガイド」
 - PV：450 PV
 - 平均滞在時間：5分 20秒
 - コメント：12件
 成功要因：
  ✓ キーワード「Instagram エンゲージメント」が月1500回検索
  ✓ 図解（投稿時間・ビジュアル・CTA の図）が分かりやすい
  ✓ クライアント事例を含めたことで信頼性向上

【低パフォーマンス記事】
記事：「ビジネス SNS 基礎知識」
 - PV：180 PV
 - 平均滞在時間：2分 15秒
 - コメント：1件
 改善案：
  → キーワードが一般的すぎた（競合が多い）
  → 実践的な内容が不足
  → 図解が少なかった

【改善施策】
 →「低パフォーマンステーマの見直し」を翌月に実施
 →「高パフォーマンスのテーマ拡張」を優先化
```

#### 2-3. 課題・原因の整理
**実行時間**: 1-2時間（月末）

分析結果から、課題と根本原因を整理：

```
【課題・原因の整理】

課題1：YouTube のエンゲージメント率が低い（3.2%）
根本原因：
 - 動画企画が YouTube ユーザーニーズと合致していない
 - サムネイル・タイトルが不十分

改善優先度：⭐⭐ 中優先
影響度：SNS 全体の成果向上（YouTube は成長ポテンシャルあり）

課題2：note のコメント数が少ない（24件）
根本原因：
 - 記事の終わりに「コメント促進 CTA」がない
 - テーマが「初心者向け」で討論性が低い

改善優先度：⭐ 低優先
影響度：note の SNS シェア・エンゲージメント向上
```

### **ステップ3：改善施策の立案**

#### 3-1. 改善施策の複数提案
**実行時間**: 2-3時間（月末）

各課題に対して、複数の改善案を提案：

```
【改善施策テンプレート】

課題：YouTube のエンゲージメント率が低い

提案1：「YouTube 動画企画の見直し」
 実施内容：
  - 来月の動画テーマを「企業向け SNS 事例紹介」に変更
  - サムネイルを図解化（テキスト少なく、ビジュアル重視）
  - タイトルに「3分で学べる」など時間 CTA を追加
 期待効果：エンゲージメント率 3.2% → 5% へ向上（月末評価）
 実行責任：SNS 運用責任者
 予想工数：週 3時間

提案2：「YouTube 専用の SNS シェア強化」
 実施内容：
  - YouTube 公開後、X・Threads で「新しい動画できました」と宣伝
  - クライアント向けに YouTube 動画も案内
 期待効果：YouTube 初期ビュー数 +50（毎月の新規視聴増加）
 実行責任：SNS 運用責任者
 実行工数：週 1時間

提案3：「YouTube アナリティクス の詳細確認」
 実施内容：
  - YouTube Studio で「視聴者がどこで動画を離れるか」を確認
  - 15秒以内に離脱する視聴者が多い場合は、冒頭の 15 秒を改善
 期待効果：動画完視率向上 → エンゲージメント率向上
 実行責任：SNS 運用責任者
 実行工数：週 2時間
```

#### 3-2. 改善施策の優先順位付け
**実行時間**: 30分（月末）

複数の改善案から、優先順位を付ける：

```
【優先順位付けの基準】

評価軸：
 1. 期待効果の大きさ
 2. 実装の容易さ
 3. 短期での成果が見込めるか
 4. 長期での成長につながるか

【マトリックス評価】
         実装が簡単 | 実装が複雑
期待大   提案1    | 提案2
        (優先)    (検討)
期待小   提案3    | (棚上げ)
        (参考)    

【優先順位】
優先1：提案1「YouTube 動画企画見直し」（期待大 + 実装簡単）
優先2：提案2「YouTube SNS シェア強化」（期待中程度 + 実装簡単）
優先3：提案3「YouTube アナリティクス分析」（参考情報）
```

## ❓ よくある質問（FAQ）

### **Q1. 月間 KPI 数が多い場合、どう優先順位付ける？**
**A.** 以下の基準で優先順位付けしてください：

```
【優先度の基準】
1. CEO が指定した最重要 KPI
2. 売上・収益に直結する KPI（営業・クライアント継続）
3. ブランド構築に関する KPI（SNS フォロワー・エンゲージメント）
4. プロセス KPI（投稿数・記事数等）

【具体例】
最優先：営業新規数・売上・クライアント継続率
重要：SNS フォロワー増加・エンゲージメント率
参考：投稿数・記事 PV（プロセス指標）
```

---

### **Q2. 改善施策、どのくらい効果を期待すればいい？**
**A.** 改善の程度に応じて、以下が目安：

```
【改善施策の期待効果】

小さな改善（施策 1-2 つ）：
 → 3-5% の改善（例：エンゲージメント率 4% → 4.2%）

中程度の改善（施策 3-5 つ + 並列実施）：
 → 10-20% の改善（例：YouTube 完視率 30% → 40%）

大きな改善（抜本的な施策 + 複数月継続）：
 → 30-50% の改善（例：フォロワー +50% 以上）

💡 注意：
- 短期（1ヶ月）では 5-10% の改善が現実的
- 本格的な改善は 2-3ヶ月単位で効果測定
- 新しい施策は「仮説→実施→検証」を繰り返す
```

---

### **Q3. CEO に改善案を提示するとき、何を優先的に提案すべき？**
**A.** CEO の関心度・ビジネスインパクトで優先順位付けしてください：

```
【CEO への提案の優先順位】

優先1：売上に直結する改善
 例：「クライアント継続率の向上」「新規営業加速」

優先2：ブランド構築（中期目標）
 例：「SNS フォロワー急増施策」「高パフォーマンスコンテンツ展開」

優先3：プロセス改善（効率化）
 例：「投稿制作の自動化」「画像生成効率の向上」

【提案する際の工夫】
- データ + 数値で提案（「フィーリング」ではなく）
- 期待効果を明示（「月 +X%」など）
- 実装難易度・工数を明記
- 複数案から CEO に選択させる（主体性尊重）
```

### **Q4. 月間 KPI が目標未達だった場合、どう報告する？**
**A.** 以下の流れで報告してください：

```
【目標未達の報告フロー】

1. 事実を正確に報告
   「新規クライアント 3 件目標に対して、2 件の獲得でした」

2. 原因分析を含める
   「理由は〇〇で、具体的には△△が不足していました」

3. 責任回避ではなく、改善案を提示
   「来月は、以下の施策を実施して、3 件以上の獲得を目指します」

4. CEO と一緒に改善策を検討
   「ご意見・ご指示をお願いいたします」

【報告のコツ】
- 言い訳・責任転嫁はしない
- むしろ「どう改善するか」に注力して提案
- CEO の信頼を失わないよう、早期に報告（月末まで黙らない）
```

### **Q5. KPI 分析、どのくらい時間がかかる？**
**A.** 月末の KPI 分析にかかる時間の目安：

```
【時間配分】
```
