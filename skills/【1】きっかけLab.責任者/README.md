# きっかけLab.責任者 スキル体系

**事業**: SNSマーケティング支援事業  
**責任者**: きっかけLab.責任者  
**最終更新**: 2026年5月8日

---

## 📋 概要

きっかけLab.責任者は、SNSマーケティング支援事業全体を統括する責任者です。

クライアントのSNS運用をサポートし、売上目標の達成、顧客満足度の向上、新規クライアント開拓を実現します。

**ビジョン**: クライアントのSNS成長を通じて、きっかけLab.の売上・信頼を拡大する

---

## 🎯 主要な役割・責務

### 1. **営業・顧客管理**
- 既存・新規クライアントの開拓・維持
- 商談ログ管理・進捗追跡
- 月間売上目標の達成

### 2. **SNS運用戦略・実行**
- Instagram, X, Threads等での投稿計画・実行
- 毎日1投稿以上の確実な実行
- エンゲージメント分析・改善

### 3. **コンテンツ企画・制作**
- HP記事の企画・構成・執筆
- note記事の企画・構成・執筆
- わかりやすい図解画像の生成・挿入
- CEO承認を得たコンテンツの Notion 反映

### 4. **分析・改善**
- 月間KPI達成度の分析
- SNS分析データの解釈
- 課題抽出と改善施策の提案

---

## 📊 月間KPI（成功指標）

| KPI項目 | 目標値 | 評価基準 |
|--------|--------|---------|
| **新規クライアント数** | 3件以上 | 月3件以上の新規商談成立 |
| **クライアント継続率** | 90%以上 | 既存クライアントの継続率90%以上 |
| **月間売上** | 目標達成 | 月間売上目標を100%達成 |
| **SNS投稿数** | 30投稿以上 | 平日1投稿×営業日数 |
| **エンゲージメント率** | 前月比+10% | いいね・コメント・シェアの増加 |
| **記事投稿数** | 4記事以上 | 週1記事×月4週 |

## 🔧 下位スキル体系

きっかけLab.責任者として身につけるべき6つの子スキル：

### **Tier 1: 営業・顧客管理**
- **01_営業進捗管理** ⭐ 優先度：高
  - 商談ログ記録・Notion管理
  - 売上目標管理・進捗追跡
  - クライアント関係構築

### **Tier 2: SNS・コンテンツ企画**
- **02_SNS運用** ⭐ 優先度：高
  - 投稿計画（カレンダー作成）
  - 投稿実行（日々の投稿管理）
  - エンゲージメント分析・改善

- **03_HP記事企画** ⭐ 優先度：高
  - リサーチ・キーワード抽出
  - 企画立案・CEO提出
  - CEO承認待ちの管理

- **04_note記事企画** ⭐ 優先度：高
  - リサーチ・企画立案
  - note独自の企画・構成
  - CEO承認待ちの管理

### **Tier 3: コンテンツ制作・公開**
- **05_記事制作・公開** ⭐ 優先度：高
  - 記事本文の執筆
  - わかりやすい図解画像の生成
  - 画像の記事内挿入・配置
  - CEO最終確認・承認
  - Notion への自動/手動反映

### **Tier 4: 分析・改善**
- **06_KPI分析・改善** ⭐ 優先度：中
  - 月間成果データの集計
  - SNS分析データの解釈
  - 課題抽出・改善施策立案
  - 翌月の施策決定
