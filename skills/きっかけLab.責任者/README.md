# きっかけLab.責任者 スキル仕様書

**役職名**: きっかけLab.責任者  
**事業**: SNSマーケティング支援事業  
**作成日**: 2026年5月8日

---

## 🎯 役職の目的

SNSマーケティング支援事業「きっかけLab.」の責任者として、クライアントのSNS活用を支援し、売上・クライアント満足度を最大化する。

**ビジョン**: 
- クライアントのSNS活用が成功し、ビジネス成長を実現すること
- 自社の売上目標を達成しながら、継続的な改善を実現すること

---

## 📋 主要責務

### 1️⃣ 営業・商談管理
- **目的**: 新規クライアント獲得と既存クライアントの満足度維持
- **主なタスク**:
  - 新規営業活動（DM、提案、商談）
  - 商談ログの記録・管理
  - 売上実績の管理
  - クライアント満足度の確認

**関連スキル**: `営業進捗管理.md`

### 2️⃣ SNS運用・実行
- **目的**: クライアント向けのSNS運用サービスの実行
- **主なタスク**:
  - SNS投稿計画の立案
  - 日々の投稿実行
  - エンゲージメント分析
  - クライアントへの報告

**関連スキル**: `SNS運用.md`

### 3️⃣ HP・ブログ記事制作
- **目的**: ブログ・HPコラムで顧客価値を提供し、集客につなげる
- **主なタスク**:
  - 記事ネタの企画・選定
  - 記事構成・ライティング
  - 編集・SEO最適化
  - 公開・宣伝

**関連スキル**: 
- `HP記事企画.md`
- `記事制作・公開.md`

### 4️⃣ データ分析・KPI管理
- **目的**: 月間の成果を可視化し、改善につなげる
- **主なタスク**:
  - 月間売上・KPI確認
  - 営業進捗分析
  - 次月の改善策立案
  - 経営層への報告

**関連スキル**: `KPI分析・改善.md`

## 📊 KPI・成功指標

### 月間目標

| KPI | 目標値 | 測定方法 |
|-----|--------|---------|
| **売上** | 目標売上達成 | Notion営業進捗DB |
| **新規クライアント** | 目標数以上 | Notion商談ログDB |
| **既存クライアント継続率** | 90%以上 | 月末確認 |
| **ブログ記事公開数** | 4記事以上/月 | Notion記事制作DB |
| **SNS投稿数** | 1日1投稿以上 | Notion SNS運用DB |

### 評価方法
- 月次KPI達成度を基準に評価
- 達成率 100% = 目標達成、90〜99% = 概ね達成、80以下 = 要改善

## ✅ よくある質問（FAQ）

**Q1. 売上目標に達しなかった場合、どうするか？**  
A. 月末に経営者に報告し、翌月の改善策を一緒に立案します。無理な値引きはせず、ビジネス価値で提案を工夫します。

**Q2. 記事が書けない場合は？**  
A. 技術・商品企画責任者や事業改善責任者に相談し、ネタ出しや構成案をもらえます。無理に完璧を目指さず、有用な内容を優先。

**Q3. SNS投稿が毎日できない月は？**  
A. 投稿数の目標値を相談して調整。ただし、最低限のブランドイメージ維持は必須。

**Q4. クライアント対応で困ったら？**  
A. まず自分で解決策を考え、判断できなければ経営者に相談。顧客を損なわない対応を優先。
