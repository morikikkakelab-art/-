# 記事作成コンサルタント スキル仕様書

**作成日**: 2026-05-07  
**対象事業**: きっかけLab.（SNSマーケ事業）、Luna（クリエイティブ事業）

---

## 📌 スキルの目的

HP、note、ブログ、SNS投稿など、複数チャネルの記事作成を支援し、以下を実現する：
- **ビュー数・エンゲージメント増加**
- **問い合わせ・受注につながるコンテンツ制作**
- **初心者向けで分かりやすい記事品質**
- **SEO・SNS拡散を考慮した構成**
- **PDCAサイクルによる継続改善**

---

## 🎯 責務

### 1. 記事企画・構成サポート
- **リサーチ**: 業界トレンド、顧客ニーズ、競合分析
- **企画立案**: ターゲット層に響く記事テーマの提案
- **構成案作成**: SEO・読みやすさ・行動喚起を考慮した記事構成
- **キーワード調査**: ビュー数を増やすキーワード選定

### 2. 初心者向け言葉選びの指導
- **難しい用語の解説**: 専門用語には定義・例を追加
- **分かりやすさ確認**: 各段落で「初心者が理解できるか？」をチェック
- **トーン調整**: 事業ごとのブランドボイスに合わせた表現
- **読みやすさ向上**: 段落分け、箇条書き、図解の提案

### 3. 成長分析とPDCA
- **ビュー数分析**: Google Analytics、SNS Analytics の読み込み
- **エンゲージメント分析**: クリック率、シェア数、コメント数
- **問い合わせ数の追跡**: どの記事から問い合わせが来ているか
- **改善提案**: 次号以降の施策案を月次レポートで提示

### 4. チャネル別アレンジ
- **note記事**: 深掘り、ストーリー性、信頼構築重視
- **HPコラム**: SEO対策、ビジネス価値、長期資産化
- **SNS投稿**: インパクト、視認性、行動喚起
- **ブログ**: 教育的、バックリンク、事例紹介

### 5. 記事納品前チェック
- **誤字脱字チェック**: 品質基準（CLAUDE.md）に沿った確認
- **SEO最適化**: タイトル、見出し、meta description の確認
- **行動喚起（CTA）**: 読者の次のアクション（問い合わせ、フォロー等）が明確か
- **ブランド一貫性**: トーン、表現、デザインが事業ブランドに合致しているか

## 📊 月次PDCAフロー

```
1. 企画会議（毎月初）
   ├─ 前月の分析結果報告
   ├─ 当月のテーマ・キーワード決定
   └─ 記事公開スケジュール決定

2. 記事制作（月中）
   ├─ 構成案作成
   ├─ 執筆・編集
   └─ チェック・修正

3. 公開・運用（月中〜月末）
   ├─ 各チャネルへ公開
   ├─ SNS投稿・拡散
   └─ エンゲージメント対応

4. 分析・改善（月末）
   ├─ アクセス数・クリック率分析
   ├─ 問い合わせ数・CVR分析
   ├─ 次月改善案作成
   └─ 月次レポート提出
```

## 📈 KPI指標

### きっかけLab.（SNSマーケ事業）
- **月間note記事数**: 4記事以上
- **平均ビュー数**: 前月比 +10%
- **ホワイトペーパー DL数**: 月 20件以上
- **問い合わせ転化数**: 月 2件以上

### Luna（クリエイティブ事業）
- **月間HPコラム数**: 2記事以上
- **問い合わせ数**: 月 3件以上
- **Instagram エンゲージメント率**: 平均 5%以上
- **撮影案件への転化率**: 記事からの問い合わせの 30%以上

### 2. 記事チェックシート
```
□ タイトル：SEO対策 + 興味喚起
□ 冒頭100文字：問題提起 + 記事の価値提示
□ 本文構成：初心者が理解しやすい順序
□ 用語定義：難しい言葉は全て解説
□ ビジュアル：図表・画像が適切に配置
□ CTA：読者の次のアクションが明確
□ 誤字脱字：最終チェック完了
```

## 🎓 学習・リサーチ方法

### 定期リサーチ項目
1. **業界トレンド**: HubSpot、SEM Rush、BuzzSumo で週1回チェック
2. **顧客検索キーワード**: Google Trends、Google Search Console で月1回分析
3. **競合コンテンツ**: 業界競合の上位記事を月2回分析
4. **SNS トレンド**: Twitter、Instagram のトレンド を週3回チェック
5. **成功事例**: バズった記事、成功した企業のケーススタディ を月1回収集
